# M3 环形扫描并行接入说明

> 状态：环形扫描 CUDA 方案已并行接入 ImagingSvc，线性扫描 pa_recon 分支保留、不做后续维护。

## 1. 总体设计

- **线性扫描分支（保留）**：`ImagingController → ImagingSvc → pa_recon_core.dll`，
  共享内存 `MC_410T_ImagingShm`、`pulse_ready/frame_ready` 信令不变。
- **环形扫描分支（新增，并行）**：
  `ImagingController → ImagingSvc → ring_recon_cuda.dll`，
  新增共享内存 `MC_410T_RingShm`、`ring_block_ready/ring_frame_ready` 信令。
- 成像模式由 configure 消息中的 `imagingMode`（`linear`/`ring`）区分；
  前端后续在交互控件中加入“线性扫描/环形扫描”选择即可。

## 2. 环形分支数据流

```
主进程（ImagingController）
  configureRing(RingReconCudaConfig, sysDelayCh[8][2])  -> 创建 MC_410T_RingShm
  submitRingBlock(rawBlock, seq)      -> 写原始 A-line 块（float32，sampDepth x alinesPerBlock）
                                          -> ZMQ ring_block_ready
子进程（ImagingSvc，ring 模式）
  processRingConfigure                 -> 解析 sysDelayPerChannel[8][2]（缺省回退 sysDelay[2] 广播）
                                          -> 创建 wl1/wl2 CUDA 句柄 + 附接环形共享内存
  processRingPulse                     -> 解交织 + ShiftWL2（前端已对齐时关闭）
                                          -> 按物理通道取各自双波长延时做 CPU 预处理截断
                                          -> ring_recon_cuda_append（逐块增量 DAS）
                                          -> wl1/wl2 帧写回共享内存 -> ring_frame_ready
主进程
  ringImageReady(wl1Img, wl2Img, seq)  -> UI 双图刷新
```

## 3. 共享内存布局（RingImagingShmHeader）

```
[0, 64)                        Header（magic=RING、block_size、frame_size、nx/ny）
[64, 64 + blockSize*4)         Ring Block Buffer（主进程写入）
[64 + blockSize*4, ...)        wl1 Frame（子进程写入）
[... , totalSize)              wl2 Frame（子进程写入）
```

## 4. 新增接口

| 位置 | 接口 | 说明 |
|---|---|---|
| `include/ImagingSharedMemory.h` | `RingImagingShmHeader` / `ringImagingShmTotalSize` | 环形共享内存布局 |
| `include/ImagingController.h/.cpp` | `configureRing()` / `submitRingBlock()` / `ringImageReady()` | 主进程环形控制与双帧回传 |
| `src/ImagingSvc/*` | `processRingConfigure()` / `processRingPulse()` / `sendRingFrameToHost()` | 子进程环形重建 |
| `src/RingReconCuda/ring_svc_selftest.cpp` | 环形链路自检 | 模拟主进程启动 ImagingSvc 并逐块喂数 |

## 7. ShiftWL2 决策（2026-08-07 同步）

按 HANDOFF 决策记录：**1064 通道首块不进行偏移**（真实采集首块无帧末列），
从第 2 块起用上一块原始末列前插对齐；首块存在约 0.09° 帧缝偏差，可接受。
- `ring_recon.cpp::splitBlock`、CPU/CUDA 验证工具、查看器均已按此实现；
- ImagingSvc 环形路径内部完成该对齐（自检直接发送原始未对齐块验证）。

## 8. 前端对接注意事项

- 前端只需选择 `configure()`（线性）或 `configureRing()`（环形），
  环形模式下通过 `submitRingBlock()` 喂入原始 A-line 块（无需预先对齐）。
- `RingReconCudaConfig` 已保留 MATLAB 主脚本全部初始化参数，前端控件直接填充。
## 9. 环形扫描控制台（M3 前端交付）

主程序 `MC410T_Receiver.exe` 的“显示控制”区新增 **环形扫描控制台** 按钮，
打开非模态控制台面板，包含：

- 采集与数据格式：数据精度（single/int16）、组包列数（默认 200）、采样深度、
  每圈 A-line 数、wlOffset、ShiftWL2 开关、采样率、A-line 速率、int16 量化因子、
  数据文件选择（模拟采集用 11.dat/14.dat）。
- 成像网格与 DAS：FOV、GridSize、Radius、CoverageDeg、Theta0Deg、FOVDeg、
  FOVTheta0Deg、Apodization、距离权重指数、插值方式、MinDistance、越界置零。
- 声速模型：声速1/声速2、分层边界数（当前 >0 时提示暂不支持）。
- 预处理：每通道波长1/波长2延时截断（`sysDelayPerChannel[8][2]`，扫描参数页随重建半径同行输入）、
  DBR mask 长度、DBR 扣除、延时截断、阈值削顶、imValue1/2。
- 显示：colorbar 范围、块间间隔。
- 右侧双波长实时图像与状态栏。

### 真实采集数据格式（已按约定实现）

- 每组包列数可调（默认 200 根 A-line 发送一次）。
- 组包数据为双波长 A-line 交替续接的一维二进制数组（未切分、未对齐）。
- 数据精度可选 single 或 int16；int16 通过“量化因子”换算回 float。
- 双波长切分与 1064 对齐在预处理（ImagingSvc 环形路径）内完成；
  真实采集接入时，前端直接调用 `ImagingController::submitRingBlock()` 喂原始块即可。

### 使用流程（模拟采集）

1. 打开主程序 → 点击“环形扫描控制台”。
2. 选择数据集（11/14）→ 选择数据文件 → 按需调整参数 → 应用参数。
3. 点击“启动环形重建”：ImagingSvc 环形模式启动，逐块喂入并双图刷新。
