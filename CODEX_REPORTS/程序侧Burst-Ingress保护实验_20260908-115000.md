## 实施方案

### Priority class

ImagingSvc 启动顺序为 QCoreApplication 构造、设置应用名、调用 ProcessScheduling::applyIngressProtectionScheduling、再构造 ImagingSvc 并进入 initialize/app.exec。

Windows 路径调用：

~~~
SetPriorityClass(GetCurrentProcess(), BELOW_NORMAL_PRIORITY_CLASS)
GetPriorityClass(GetCurrentProcess())
~~~

priority Apply 失败只进入 priorityApply=error:<win32>，不阻止 ImagingSvc 继续初始化；effective priority 仍通过 GetPriorityClass 查询并记录。没有使用 IDLE、HIGH 或 REALTIME，也没有改变 receiver thread priority。

### Process affinity

使用 GetProcessAffinityMask 取得 original process mask 和 system mask。纯函数 computeRequestedAffinity 的规则是：

1. 对 processMask & systemMask 计数，少于 4 个可用 logical processor 时保持原 mask，记录 skipped:insufficient_logical_processors；
2. 可用处理器不少于 4 个时，仅从当前有效 process mask 清除 CPU0 和 CPU2；
3. 清除后为 0 时禁止 SetProcessAffinityMask(0)，记录 skipped:zero_mask_prevented；
4. CPU0/CPU2 本来都不在当前 mask 时保持原 mask，记录 skipped:reserved_cpus_not_present；
5. SetProcessAffinityMask 成功或失败都记录结果，随后再次 GetProcessAffinityMask 记录 effective mask。

因此 ImagingSvc 的普通 CPU worker threads 继承 process-level scheduling boundary；没有 pin Qt main thread、修改 receiver core 2、修改 RSS/interrupt affinity 或要求管理员权限。
