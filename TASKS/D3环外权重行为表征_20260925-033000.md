**本任务的全部意义来自前提文档 E1**：现有权重 `w = Δθ·apod·cosα/d`，UBP 权重
`dΩ = R·Δθ·cosα/d²`，两者相差 `R/d`。而 `cosα = (R − r·n̂)/d` 在像素位于探测环之外时
**会变号**，UBP 的 `dΩ` 因此**带符号**、环外翻转。**B1 必须据此处理，不得默认沿用
现有 `accW += |w|` 的绝对值累加语义而不作说明。**

## 4. 具体要求

1. **变号边界**：求 `cosα = 0` 的几何轨迹（即 `r·n̂ = R`），给出它在 FOV 内的形状与范围。
2. **变号像素占比**：FOV 内 `cosα < 0` 的像素数占比；并按「距环心半径」分档给出。
3. **权重空间行为**：给出 `w_现有 = Δθ·cosα/d` 与 `dΩ = R·Δθ·cosα/d²` 沿若干代表性
   射线（环内 / 环上 / 环外）的数值曲线或关键点数值，含二者的比值 `R/d` 验证。
4. **`minDistance` 保护的实际覆盖**：`minDistance = gridSize = 10 µm`，判断它在本几何下
   是否真的能约束 `d → 0` 的奇异（环半径 6.57 mm 远大于 10 µm，需给出结论）。
5. **符号处理候选**：列出 B1 在环外像素上的可选处理（保持符号 / 取绝对值 / 掩膜截断），
   并**只陈述各自的结构性后果**（例如对 R1 比值守卫是否安全），**不做优劣预判**。
6. **拼接模式影响**：`spliceMode=1` 时每像素仅被 `360/M` 扇区的 A-line 命中
   （`ImagingSvc.cpp:648` `sectorWidthDeg = 360.0/M`），此时权重和 `Σ|w|` 的量级与
   全局模式差异多大（对归一化选择有直接影响）。
