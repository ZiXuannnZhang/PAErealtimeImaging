# 环形重建增强（未验收实现）

状态：实现候选，尚未实机验收，不代表 canonical main 已接受能力。

## 1. 功能边界

本实现只作用于环形扫描实时重建输入：

```text
ImagingSvc::processRingPulse
  -> ringrecon::preprocessBlock
  -> RingSignalEnhancer
  -> ring_recon_cuda_append_angles_radii*
```

包含两个独立信号域算子：

1. 低频补偿：
   ```text
   H(f) = 1 + (Hmax - 1) * exp(-(f/fc)^order)
   ```
2. 双极波形补偿：
   ```text
   g(t) = p_c(t) - t*d(p_c(t))/dt
   ```

固定约束：

- `lambda(t)=t`，不提供 `lambdaSlope` 参数；
- 不执行正整流，输出保持 signed DAS；
- 不修改 raw、保存、发布、前端显示或线性 `pa_recon_core` 分支；
- 不包含距离/介质传播补偿。

## 2. 配置

“环形扫描参数设定 -> 重建参数 -> 重建增强”：

| 参数 | 默认 | 含义 |
| --- | --- | --- |
| 启用双极波形补偿 | false | 执行固定 `lambda(t)=t` 的导数补偿 |
| 启用低频补偿 | false | 执行固定 `H(f)` 曲线 |
| fc(MHz) | 10.0 | 低频补偿转折频率 |
| Hmax | 2.0 | 零频最大增益 |
| curve order | 2.0 | 高频趋近 1 的曲线阶数 |

两项功能独立开关，可以分别 A/B。配置由 `RingEnhanceConfig` 承载，不扩展
`RingReconCudaConfig`，因此不改变 `ring_recon_cuda.dll` ABI。

## 3. 信号顺序

```text
DBR / 限幅 / DelayCut
-> H(f) 低频补偿
-> 中心差分 dp/dt
-> 乘 t 并翻转
-> signed DAS
```

H(f) 对完整 A-line 独立执行。生产实现采用反射延拓和 FFT/IFFT；两个波长共享同一组频域参数。时间零点为 DelayCut 后第一个保留采样点。

### 3.1 边界延拓方法（A1 固化）

H(f) 以 FFT/IFFT 实现时，先把 DelayCut 后的保留段填充到 2 的幂长度。当前生产实现的填充方式是**整样本对称反射延拓**（whole-sample symmetric reflection，沿保留段两端按 `x[-1-n] = x[1+n]` 镜像，周期 `2(N-1)`），**不是补零**：

- 反射延拓保持边界 C₀ 连续，延拓后的序列 DFT 为实；H(f) 为实增益，乘实增益后频谱仍实，逆变换保持零相位，不引入相位失真；
- 补零等价于对信号乘矩形窗，其与低频提升核在频域卷积，会在段边界产生起振/振铃伪迹（提升量越大越明显），故不采用；
- 时间零点（双极补偿的 `t=0`）仍为 DelayCut 后第一个保留采样点，反射填充不改变该约定。

已知边界性质：反射拼接点处信号本身连续（C₀），但**一阶导数符号翻转（C₁ 斜率翻转）**。影响面：H(f) 的低频提升核在时域越长（fc 越低、Hmax 越大），拼接点斜率不连续经逆变换泄漏到段两端的痕迹越明显；对高频为主的保留段主体影响可忽略。该性质随实现固化，不作为参数暴露。

**奇延拓（odd extension）替代方案评估结论**：奇延拓可使拼接点 C₁ 连续，能进一步抑制边界伪迹，但会把偶序列变为奇序列，DFT 虚部非零，需要额外的相位处理与配置面。按预算任务（`CODEX_REPORTS/ring-enhance-budget-20260927-151919/`）的验收路径，仅当后续图像 A/B 对比显示**可见的边缘伪迹**时，才新增 `boundaryMode` 配置实现奇延拓；当前默认不加该配置面。

## 4. 与现有 DAS 参数的关系

- `Apodization` 仍是 A-line 角度窗；
- `距离权重指数` 仍是 DAS 几何距离权重；
- `MinDistance` 仍是距离权重分母的数值下限。

三者不与 H(f) 或导数补偿合并，也不承担低频/深度补偿语义。
