4. **maskLength 动态调整相容结论**（用户将自行调整，harness 现值 0）：
   - preFilter 在置零**之前**（顺序保证）：置零对 preFilter 处理有效信号零影响，任意 maskLength 成立；

5. **滤波口径**：归一化截止 `Wn = 2*f/fs`，fs=250e6（真实采样率）；老代码 `DAQ=200e6` 是 14.dat 时代历史字段，**禁止使用**。filtfilt 逐列=逐 A-line 独立、无跨线状态。

## 工作一：⑤ 区补偿后滤波预设块

在 ② 区 B（显示与指标开关）之后、指标参照定位之前插入 ⑤ 区 E：

```matlab
%% ---------- ⑤ 区 E：补偿后滤波预设（postFilter，挂在变体上） ----------
% 结构与 ④区 preFilter 同构；补偿后、DAS 前，作用在 DelayCut 后窗口上。
% 只用 filtfilt（零相位、无 FFT 泄露）；POST_OFF 透传（与未加滤波逐位一致）。
POST_OFF  = localPostPreset(0, 0);      % 透传
POST_LP20 = localPostPreset(1, 20);     % 低通 20 MHz
POST_LP30 = localPostPreset(1, 30);
POST_LP40 = localPostPreset(1, 40);
POST_LP60 = localPostPreset(1, 60);
% 需要高通时直接改字段：POST_LP30.hpEnable=true; POST_LP30.hpCutoffMhz=0.4; 等
```

配套本地函数（结构与 `localVariant` 同风格）：

```matlab
function pf = localPostPreset(lpEnable, lpCutoffMhz)
pf = struct('hpEnable', false, 'hpCutoffMhz', 0.4, 'hpOrder', 4, ...
    'lpEnable', logical(lpEnable), 'lpCutoffMhz', lpCutoffMhz, 'lpOrder', 4);
end
```

并在预设块后加 toolbox 断言（仅当任一变体启用 postFilter 时触发）：

```matlab
if any(arrayfun(@(v) v.postFilter.hpEnable || v.postFilter.lpEnable, variants))
    assert(~isempty(which('butter')) && ~isempty(which('filtfilt')), ...
        '启用了补偿后滤波：需要 Signal Processing Toolbox（butter/filtfilt）。');
end
```

（该断言须放在变体矩阵构建之后；预设块与矩阵的先后按脚本现有分区顺序安排。）

## 工作四：localEnhanceVariant 插入补偿后滤波

双极算子输出之后、返回之前插入一行（**复用** `localFrontendFilter`，不新写滤波逻辑）：

```matlab
g = o.alphaP * p - tvec .* dp;
g = localFrontendFilter(g, fs, o.postFilter);   % 补偿后滤波：POST_OFF 透传，逐位不变
```

注意：`localEnhancedSignalRef`（自检对账副本）**不得**插入此调用——自检的 BASE 行 postFilter=POST_OFF 时统一算子仍须与基准逐字算子逐位一致。

## 工作五：头部 RMS 诊断

第一遍变体循环内，对启用 postFilter 的变体（任一波长，取 wl==1）打印滤波前后窗口头部（前 64 样本）RMS 变化率，量化 filtfilt 边界瞬态对环心（t≈0）的潜在影响：

```matlab
% gRaw 为滤波前算子输出；ratio = rms(g(1:64,:) − gRaw(1:64,:)) / rms(gRaw(1:64,:))
fprintf('  [postFilter 诊断] %s 头部64样本 RMS 变化率 = %.3g\n', o.tag, ratio);
```

实现时先算 `gRaw` 再滤波（仅启用时多保留一份）；诊断只打印、不进 summary。
