## 3. D6 具体要求

1. 用 **D4 的度量工具**，对**同一份数据**分别在
   **`spliceMode = 0`（全局反投影）** 与 **`spliceMode = 1`（逐通道扇区拼接）** 下
   跑全套指标。两模式差值 = **有限视角贡献的直接量化**。
2. 指标：轴向/切向分辨率、位置误差、CR、gCNR、背景噪声、CNR，**外加双波长比值守卫**。
3. **禁止**对输入做逐图归一化或显示拉伸后再度量（R1）。
4. 记录数据 SHA256、配置、构建 BuildIdentity、度量工具版本。

## 4. D7 具体要求

1. 构造**合成体模**（已知真值：点目标、均匀盘、双波长已知幅值比），前向模型用
   与项目一致的几何（`radius=6.57mm`、8 通道、`daqHz=250e6`、`sampDepth=4000`、
   分层声速 `{1490,1540}`、`fov=36mm`、`gridSize=10µm`）。
2. 分别重建：**现有 DAS**（`w = Δθ·cosα/d` + `p`）与 **UBP 成对**
   （`w = R·Δθ·cosα/d²` + `b = 2p − 2t·p′`，**t 用秒**），用 D4 度量对比。
3. 两种模式（`spliceMode` 0/1）各跑一遍。
4. 给出**上限评估**：在理想（无噪声、带宽充足）条件下 B1 相对 DAS 的可改善空间；
   并单独给出**加噪后**的变化趋势（噪声水平取 D1 的实测值，若 D1 未完成则用标注假设）。
5. **不预设优劣**：若 B1 在某些指标上更差，如实报告。
