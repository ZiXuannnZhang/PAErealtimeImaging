## 实施结果

本次只增加单槽 Ring SHM 链路观测，不改变协议所有权、背压策略、共享内存布局或重建流程。

- 新增 delivery/include/RingShmObservability.h：线程安全的 session/epoch 计数器、uint32_t 序号连续性判断、ready 通知兼容解析、队列/拷贝锁/处理耗时和 JSON 快照。
- ImagingController 在现有 SHM 锁内记录写入前的 block_ready/block_seq，统计提交数、覆盖风险、提交间隔，并在 ready JSON 中加入可选 submit_index/submit_wall_us；生产异常和服务遥测统一通过现有 svcStatus 输出稳定前缀 [RingSHMObs]。
- ImagingSvc 在现有 SHM 锁内记录通知序号、当前 SHM 序号、ready-before-copy、拷贝锁耗时；检测通知/SHM 不一致、ready=0、重复、跳号；支持 start 会话、ring reset epoch、周期（32 次）、异常和最终汇总遥测。
- ring_svc_selftest 记录生产端计数、接收服务端遥测，并在 14.dat 自测结束时打印两端汇总。
- 新增 ring_shm_observability_test 覆盖 T1–T11、T13；T12 使用现有 Windows 外部自测完成。

## 不变量和变更边界

- RingImagingShmHeader 未修改；sizeof(RingImagingShmHeader)==64 由静态断言和测试验证。
- ImagingSharedMemory.h、RingBlockAssembler.*、CUDA/reconstruction 实现未修改。
- 未改变 block_ready/block_seq 写入顺序、清零时机、raw/angle/channel/frame 偏移和现有 snapshot 通知。
- reset 只清空序号连续性状态并递增 epoch，避免跨圈/跨会话产生假跳号；uint32_t 最大值到 0 的回绕按连续处理。
