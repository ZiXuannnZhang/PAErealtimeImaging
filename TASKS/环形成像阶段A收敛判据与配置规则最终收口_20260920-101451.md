## 7. Recommended Design / 执行要求

### C1：排除自比，要求不同窗口稳定，并有失败负例

将收敛判断提取为可测试的小函数或统一逻辑，由 test_boundary_reference 与 exp5 使用，避免两份标准漂移。保留现有相对容差1e-9及p/p′/b分别的有效尺度，不用调整阈值掩盖失败。

具体通过标准：

1. padRef 只作参考，pad==padRef 项禁止作为通过候选。
2. 至少两个不同的非参考pad值参与判断；两者与参考的p/p′/b误差均在容差内。
3. 这两个pad对应结果之间也应稳定（同一参考尺度下误差在规定容差内），且从声明的收敛起点到最大非参考pad不能出现再次超差。报告实际采用pad值、各分量误差和相邻/两窗差。
4. 候选不足、误差非有限、尺度或形状不合法、全部候选超差时判失败，不能空数组 all() 真值通过。
5. 最大参考是否足够仍是数值近似：以多个非参考窗口的稳定结果支持，不宣称严格数学证明。对已有起点/尾端敏感性结果，应在其实际报告区间用至少两个不同长窗口核对稳定性，避免只验证中心目标区间就声称所有边界结果已收敛。

必须添加针对判据本身的廉价负例（可用人工误差表，不必重跑完整前向）：

- 只有参考自比误差为零、其余全超差 → 必须失败。
- 仅一个非参考pad通过 → 必须失败。
- 两个较小pad通过但更大非参考pad再次超差 → 必须失败。
- NaN/Inf、没有候选 → 必须失败。
- 至少两个非参考pad形成满足规则的稳定尾段 → 必须通过。

保留实际pad曲线。不要把旧自比样本从输出中删除作为唯一修复：可留作诊断，但明确不计入验收。

### C2：冻结接受/拒绝规则并提供参考校验测试

仅针对本任务新增处理定义下面的前置规则；全部新功能关闭时不引入新拒绝条件，保持旧行为。

定义：

```
filterEnabled = highpassEnabled || lowpassEnabled
inversionEnabled = 光声反演开关
D = 当前通道/波长 systemDelay
E = 当前A-line实际DBR置零样本数
```

E 应依据真实预处理语义计算并在参考中显式表达：DBR关闭时E=0；DBR开启但有效置零长度为0时E=0，不等于“开关开启就一定存在阶跃”。有效置零长度需计入该波长dbrmaskExtra和实际样本数边界；不要在不同文档中混用配置值与实际长度。无效参数本身如何处理沿用既定校验，不用截断静默修复非法配置。

| 条件 | 本版决定 |
|---|---|
| filterEnabled=false | 不触发零相位滤波专属拒绝；仅反演保持既定有效查询/导数端点规则 |
| filterEnabled=true，E=0 | DBR相关规则允许；仍需满足采样率、截止、阶数和长度校验 |
| filterEnabled=true，E>0，delayCut=true | 仅当E<D允许；E>=D明确报错 |
| filterEnabled=true，E>0，delayCut=false | 明确报错，不支持该组合；不留给阶段B任选 |

上述规则逐启用通道/波长检查，有一条不满足即拒绝应用本组配置，并报告具体通道/波长与原因，不只检查全局默认D。

参考错误语义可采用：
- “零相位滤波与未裁剪的DBR置零前缀不兼容，请启用延时裁剪或取消DBR置零。”
- “DBR置零末端必须早于该通道/波长的延时裁剪起点。”

当前仅实现参考配置校验及测试，不接入生产UI。单独验证HP/LP/两者、反演开关两态、DBR开关、E=0/E=D−1/E=D/E>D、D=358/371，以及一通道失败应整组拒绝。反演单独开启不因本表错误触发HP/LP限制。

不能把上述配置允许理解为无边界误差或目标无损保证。保留已量化的起点/尾端误差和实机UNVERIFIED限制。

### C3：唯一查询规则，同步所有规范位置

统一变量：D为raw一基声学零点；T为物理走时秒（含双声速分区计算）；s=fs*T；m为raw一基连续位置；q为当前数组零基连续位置。

| 功能组合 | delayCut=true | delayCut=false |
|---|---|---|
| 全部关闭 | q=s，保持旧行为 | q_legacy=s，保持旧行为 |
| 仅HP/LP | q=s，保持旧行为 | q_legacy=s，保持旧行为；先通过C2组合校验 |
| 反演开启（±HP/LP） | q_cut=s，m=s+D | q_raw=s+D−1，m=q_raw+1=s+D；先通过C2组合校验 |

反演乘子恒为t=T=s/fs，而不是把q_raw直接除fs。已存在的两态导数端点差异仍按既定规则报告，不承诺所有端点逐位等价。

删除所有“反演/滤波启用时都补偿”的歧义；改成“只有反演开启才使用校准的未裁剪查询”。本表为本轮确定建议，无需再提出“强制delayCut=true”替代选项；未来范围变更需单独审查。

同步 algorithm-stage-A 摘要、§2/§3/§7、review-spec-closure、review-remediation 的现行结论、README、exp5 res.policy及重新生成的JSON。历史原错误可通过Git追溯，正文引用旧结论必须标为已撤回。
