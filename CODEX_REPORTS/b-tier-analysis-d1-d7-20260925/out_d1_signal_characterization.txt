--- 1. 记录长度判定（证据） ------------------------------------
判据：真实记录（=一次触发 = 一根 A-line）应在每个记录起点出现一致的
“静默前缀 + 启动 ring-down”结构。对 50000 与 10000 两种候选分别检验
每块内全局峰值的样本位置一致性。
文件 Card1_ChA_test_000.dat
  按 10000 分块的峰值样本位置（前 20 块）: 443 445 445 444 444 446 445 445 444 446 446 445 445 444 443 443 443 445 444 443
  按 50000 分块的峰值样本位置（前 5 块） : 30444 30444 10445 30444 443
  10000 分块下峰值位置极差 = 3 采样点（稳定）
  50000 分块下峰值位置极差 = 30001 采样点（不稳定）
  => 记录长度 = 10000 采样点。

--- 2. 逐通道 × 逐波长数字表 -----------------------------------

口径定义：
  噪声底 RMS      静默区段 [0, 400) 采样点的均方根（触发延迟前，无回波可到）。
                  另给“全场最低滑窗 RMS”（单条 A-line 上窗长 256 的滑窗 RMS 最小值，
                  对每 8 条取 1 条求平均）作为交叉核对。
  噪声底 峰值     静默区段内 |v| 最大值。
  信号有无        max|v|/噪声RMS > 4 判为有信号。纯量化噪声通道该比值 = sqrt(3) = 1.732
                  （均匀分布），有回波通道远大于 1。
  有效带宽        Welch 平均功率谱（Hann 窗 4096 点，50% 重叠，每 8 条取 1 条）上的
                  -3 dB / -6 dB 带宽与中心频率（按功率谱重心）。
  脉冲主瓣宽度    过峰值点取线剖，|v| 降到峰值的 -6 dB / -20 dB 处的全宽。
  旁瓣比          主瓣外最大 |v| / 主瓣峰值，dB。
  过零结构        主瓣内符号变化次数。
  SNR             回波峰值 / 噪声底 RMS（线性幅度比，不取对数后比）。

已处理 32000 条 A-line 记录（64 个文件）。

【重大数据充分性发现】
  testdata/01 的 8 个物理通道中，仅 Card1_ChA 含真实光声信号；
  其余 7 个通道的 max|v|/噪声RMS = 1.73~1.75 ≈ sqrt(3)，幅度分布近似均匀，
  是纯量化噪声（无回波）。这意味着：
  - 噪声底、双波长一致性：8 个通道全部可测，结论有效；
  - 有效带宽 / 脉冲形状 / SNR / 导数可行性：只能在 Card1_ChA 上测，
    其余通道表 2.2/2.3 的数字描述的是【噪声】不是【信号】，不得当作信号特性使用。
  证据层如实标注：这是历史实测数据的内容事实，不是合成假设。

--- 5. 导数可行性判定（B2「导数前先低通」） --------------------

物理口径：微分在频域乘 j*2*pi*f，即 +6 dB/oct 高通。设噪声功率谱密度 S_p(f)、
低通截止 fc，则
    var(p)       = integral_0^fc S_p(f) df
    var(dp/dt)   = integral_0^fc (2*pi*f)^2 * S_p(f) df
先低通再求导，等价于把积分上限截到 fc。

【公平比较口径】不能把“原始 SNR（全带宽）”与“微分 SNR（低通后）”直接比。
B2 的问题是：同样的低通 fc 下，B1 的信号项 2p - 2t*p'（t 用秒，t=r_tilde/c）
相对 DAS 的信号项 p，SNR 变差多少。因此本任务比较
    SNR_DAS(fc) = |p(t0)| / sqrt(var(p, fc))
    SNR_B1 (fc,t0) = |2p(t0) - 2*t0*p'(t0)| / sqrt(var(2p-2t*p', fc))
其中 var(2p-2t*p', fc) = integral_0^fc |2 - 2*t0*j*2*pi*f|^2 * S_p(f) df
                  = integral_0^fc 4*(1 + (2*pi*f*t0)^2) * S_p(f) df

噪声谱：取 7 个无信号通道 + Card1_ChA 触发前静默段的 Welch 平均（见 §2）。
信号 p：Card1_ChA/wl1 的 2000 条平均波形（近似无噪）。

噪声谱归一化自检：integral S_p(f) df = 1.2323e+3（均方）  =>  RMS = 3.5103e+1
                   实测触发前噪声方差（16 组平均） = 1.2308e+3  =>  RMS = 3.5083e+1
                   相对偏差 = 0.115 %

  【数据充分性限制】testdata/01 中仅 Card1_ChA 一个物理通道含真实光声信号，

  判定【只建立在 1/8 个物理通道上】，不构成全部通道的结论。
