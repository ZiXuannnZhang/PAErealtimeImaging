原报告把「有哪些算法」回答好了，但**两处事实错误会把实现引向错路**：
E1（UBP 权重判断错误，差 `R/d`）与 E2（单极性过度声称）。**在修正这两条之前，

## 2. 事实错误

### E1【高】UBP 权重「同形」判断错误 —— 差 `R/d`

**原报告说法**（§0 与 §5.1）：MATLAB/CUDA 默认权重
`w ∝ (r·r_s − R²)/(R·|r−r_s|²)·arc·apodization`（默认 `DistanceWeightExponent=1`）
「正是圆环几何 UBP 的反投影权重形式」，并据此给出改造路线「换信号项、权重基本不动」。

**`[代码实测]` 现有实现**（`src/RingRecon/ring_recon_cuda.cu`）：

```cpp
// :615-617  arc = 逐线平均角步长（弧度）
// :648     wscale[j] = -arc * apod;        // apod 默认 1.0
// :337-346 pw = wExponent + 1 (=2);  dsafeP = dsafe*dsafe;
//          wBase = wscale[j] * dotp / (Rj * dsafeP);
//          dotp = proj - R2j = r·r_s - R²
```

展开（令 `d = |r − r_s|`，`n̂ = r_s/R`，`cosα = (R − r·n̂)/d`）：

```
w = -Δθ·apod·(r·r_s − R²)/(R·d²)
  =  Δθ·apod·(R² − r·r_s)/(R·d²)
  =  Δθ·apod·(R − r·n̂)/d
  =  Δθ·apod·cosα / d
```

**`[文献]` UBP 的立体角权重**（Xu & Wang, PRE 71, 016706 (2005) Eq.(22)）：

```
dΩ₀ = dS₀·(n̂₀·(r − r₀))/|r − r₀|³ = dS₀·cosα/d²
环上 dS₀ = R·Δθ  ⇒  dΩ₀ = R·Δθ·cosα/d²
```

**`[推导]` 两者之比**：

```
dΩ₀ / w_现有 = (R·Δθ·cosα/d²) / (Δθ·cosα/d) = R/d
```

⇒ **两者不同形，差一个随像素变化的 `R/d`。** 原报告描述的 `Δθ·cosα/d` 是 **DAS 的
权重**，不是 UBP 的 `R·Δθ·cosα/d²`（原报告自己的括注写「余弦 / 距离」，而 UBP 是
「余弦 / 距离² × R」）。

**后果**：原报告 §5.1 的路线「信号域换成 `2p−2t·p′`、权重基本不动」产出的是
**任何文献里都不存在的混合体**，既不是 DAS 也不是 UBP，无法用文献结论背书、
也无法用文献指标对比。**这是本说明最重要的一条更正。**

**正确做法**：信号项与权重**成对**切换（见 §3）。

### E2【高】「UBP 输出单极、非负」与原报告 §2.2/§4.2 自相矛盾

**原报告说法**（§2.1）：UBP「输出物理量：…吸收能量密度（单极、非负物理量）…
这是 UBP 相对 DAS 在『单极性』上的根本区别」；§0、§6.2 据此推出「单极输出对逐像素
比值更友好」。

**同一报告的另两处**：§2.2「负值伪影两大根源 = 有限带宽 + 有限视角…**该结论对整个
反投影族（含 DAS/UBP）成立**」；§4.2「反投影族（DAS/UBP）都受负值伪影影响」；
§2.2 还引用 Hakakzadeh IUS 2022，其中 **UBP 是双极基线**（半视角 gCNR = 0.64）。

**事实** `[文献]`：UBP 重建的是**初始声压 p₀ = Γ·A**（Γ 为 Grüneisen、A 为吸收能量密度）。
「非负」是**物理前提**（吸收系数非负），**不是算法输出的保证**。带限与有限视角会让
重建结果照样出负值（Shen 等, J. Phys. D 54, 074001 (2021) 已系统化其机理）。

**后果**：把「理想物理量非负」写成「算法输出单极」，会让后续把 sO₂ 比值稳定性
建立在一个不成立的前提上。**R1 因此必须独立成立，不能指望算法自带单极性。**

## 3. 关键遗漏

### G1 2D / 3D 精确性边界（决定 UBP 能声称到什么程度）

`[文献]` Xu & Wang UBP 的严格性要求：(a) **完整闭合**探测曲面；(b) 源**紧支撑在面内**。
3D 满足 Huygens 原理 ⇒ 局部反投影成立；**2D 不满足**（Green 函数有尾部）⇒ 严格 2D
反演需要**非局部（log 核）滤波**（Finch–Haltmeier–Rakesh）。

本项目是**环形阵 + 2D 成像网格** ⇒ UBP 在本项目**只能是近似**。
**不得**按「解析精确」设计，**不得**在报告/文档中作此声称。

### G2 恒等式（E1 的理论根据）

`[推导]` 可自验：

```
b = 2p − 2r̃·∂p/∂r̃ = −2r̃²·∂/∂r̃ ( p / r̃ )
```

（展开右端：`−2r̃²[p′/r̃ − p/r̃²] = −2r̃ p′ + 2p` ✓）

含义：导数项**不是**裸的 `dp/dt`，而是对 `p/r̃` 做**随距离加权的径向微分**。
因此 `2p` 与 `−2r̃ p′` 缺一不可，且**系数里的 `r̃` 是像素相关的**——滤波无法提成
固定卷积核预计算一遍。这也是 R2 的理论根据：**信号项与权重是一个整体**。

### G3 双波长比值的真正危险源（R1 的具体化）

`[代码实测]` 快照归一化为 `out = acc / max(accW, 1e-12)` 再做块平均
（`ring_recon_cuda.cu:355-382`），`accW` 累加 `|w|`，而 `w` **只含几何量**
（`Δθ·apod·cosα/d`，与波长无关）⇒ **两个波长的 `accW` 完全相同**。

| 操作 | 双波长比值 |
|---|---|
| `acc/accW`（accW 纯几何） | ✅ **安全**（两波长同除一个量，比值不变） |
| 常数 `Ω₀` 归一化 | ✅ 安全 |
| **逐图峰值归一化 / 显示拉伸进数据链** | ❌ **破坏** |
| **硬整流（负值置零）** | ❌ **破坏**（非线性 + 引入偏差） |
| **Hilbert 取模后作定量输入** | ❌ **破坏**（非线性） |

**结论**：原报告把 `NormalizeByW` 当语义问题（这一点对，见 §3.1/B3），但**没接到
双波长定量**这条线上。真正的危险不是 `accW`，而是逐图归一化与整流。

### G4 微分型信号项放大噪声

微分在频域是 **+6 dB/oct** 高通。B1 的信号项 `2p − 2t·p′` 含导数项，**必须先低通
再求导**（B2），否则会比现有 DAS 更噪。可行性取决于实测噪声底（D1），
不得凭假设实施。

### G5 成像路径已有零相位滤波（会级联）

`[代码实测]` `FrontendPreprocessor::dispatch`（`src/FrontendPreprocessor.cpp:307-336`）
把滤波后的 frontend clone **同时**喂 `DisplayBuffer::update` 与 `ring()`。
即：**实时成像吃的是前端滤波后的数据**。B2 若在重建侧加低通，会成为成像路径上的
**第二级滤波**。必须先定分工口径，**不得让成像数据被零相位滤两次**。

### G6 Hakakzadeh 2022 不可复现，不能作对照基线

该文（IUS 2022）全篇**无编号公式**，算法以 6 步文字流程给出；第 3 步
「a positive dynamic time-based slope ( ) is multiplied to the generated signals」
的**符号在 PDF 文本层提取为空**（字体编码丢失或原文即缺），增益形式/量纲/随时间
变化规律全篇未给。⇒ **照文无法复现**，不能作为 A/B 对照基线，也不能作为
「单极化」方案的实现依据。原报告 §8 把它列为「对比实验设计」对象，需修正。

## 4. 对各任务类型的具体影响

### 4.1 分析/表征类（D1、D2、D3、D6、D7）

- 度量口径必须包含**双波长比值守卫**：同一线性算子处理 wl1/wl2，断言输出幅值比
  = 输入幅值比。这条是**判别性测试**，会直接判死「逐图归一化/整流」类方案。
- 所有指标以**当前 `main` 行为**为基线；必须记录数据 SHA 与配置来源（E3）。
- 证据四层分离：source/code correctness ／ automated tests/build/selftest ／
  real hardware validation ／ hardware root-cause attribution。**不得把软件 PASS
  写成实机 PASS。**

### 4.2 实现类（S3、S4）

- **禁止**照原报告 §5.1「只换信号项、权重基本不动」实施（E1）。
- B1 权重必须实现为 `R·Δθ·cosα/d²`，与信号项 `2p − 2t·p′` **同时**开关。
- `t` 用**秒**（`t = r̃/c`）；用采样点会差 `fs` 倍。
- 拼接模式（每像素仅被 ~`360/M` 扇区的 A-line 命中）下，UBP 的常数归一化 `Ω₀=4π`
  会带来严重幅值误差 ⇒ **优先 `Σ|w|`（`accW`）归一化**；两者都比值安全，属标度决策。
- 环外像素：`radius = 6.57 mm` 而 `fov = 36 mm` ⇒ **FOV 大部分像素在探测环之外**，
  `cosα = (R − r·n̂)/d` 会变号 ⇒ UBP 的 `dΩ` **带符号**、环外翻转。必须按 D3 的
  表征结果处理，不得默认沿用现有 `|w|` 累加语义而不作说明。

### 4.3 文献补查类（D5）

- 优先补 G1（2D 严格性边界）——它决定 UBP 在本项目能声称到什么程度。
- 每条结论必须标核实等级；**标注「未完全核实」「间接核实」的不得作为设计依据**
  （沿用原报告自己的纪律）。
