# M2 CUDA 重建可视化验收方案与引导

> 适用对象：M2 双波长环形 DAS 重建（CUDA 内核）的可视化验收。
> 查看器 `ring_recon_view` 支持 `--engine cpu`（M1）与 `--engine cuda`（M2），
> 左右双图同步刷新，界面与 MATLAB 主脚本 imagesc 双图一致。

## 1. 验收前置条件

- CUDA Toolkit 12.8 已安装，GPU：RTX 4060（sm_89）。
- 数据文件：`D:\zzx\data\20260716\11.dat`、`D:\zzx\data\20260519\14.dat`。
- 查看器已构建（含 CUDA 引擎）：`delivery\build_ring_recon_view.cmd`。

## 2. 构建查看器（含 CUDA 引擎）

```powershell
cd MC_410T_MultiCard\delivery
.\build_ring_recon_view.cmd
```

产物：`build\ring_recon_release\bin\ring_recon_view.exe`
（同目录已自动部署 Qt/MinGW/CUDA 运行库，无需手工加 PATH）。

## 3. 验收步骤

### 3.1 VSCode 方式（推荐）

打开工作区后，调试面板选择以下配置直接 F5：

| 配置名 | 引擎 | 数据 |
|---|---|---|
| Run RingRecon View (11.dat) | CPU | 11.dat |
| Run RingRecon View (14.dat) | CPU | 14.dat |
| Run RingRecon View CUDA (11.dat) | CUDA | 11.dat |
| Run RingRecon View CUDA (14.dat) | CUDA | 14.dat |

### 3.2 命令行方式

```powershell
# CPU 引擎
build\ring_recon_release\bin\ring_recon_view.exe --data D:\zzx\data\20260716\11.dat --id 11 --grid-mm 0.1 --block 200 --engine cpu --sleep-ms 50

# CUDA 引擎（M2 验收）
build\ring_recon_release\bin\ring_recon_view.exe --data D:\zzx\data\20260519\14.dat --id 14 --grid-mm 0.1 --block 200 --engine cuda --sleep-ms 50
```

参数说明：`--engine cpu|cuda`、`--grid-mm` 网格尺寸、`--block` 每块 A-line 数、
`--sleep-ms` 块间停顿、`--auto-quit 1` 跑完自动退出（无界面自检用）。

## 4. 观察点与通过标准

1. 窗口显示左右两幅灰度图：左=532nm（wl1），右=1064nm（wl2），逐块累积刷新。
2. CUDA 与 CPU 引擎跑同一数据，最终图像结构/对比度视觉一致
   （环形扫描血管结构清晰、无明显缺失或错位）。
3. 状态栏“本块 ms”显示 CUDA 明显低于 CPU：
   - 360x360：CPU 约 86~155 ms，CUDA 约 15~21 ms；
   - 720x720（`--grid-mm 0.05`）：CPU 约 329~583 ms，CUDA 约 22~24 ms。
4. 全程无弹错、窗口不卡死；14.dat 为 40 块、11.dat 为 20 块，跑完状态栏显示累计耗时。

## 5. 量化佐证（非视觉复核）

CUDA 与 CPU 逐块输出对照（排除探测器奇异区，容差 1e-3）：

```powershell
python MC_410T_MultiCard\delivery\tools\compare_ring_recon.py `
  build\ring_recon_out11 build\ring_recon_cuda_out11 360 360 20 --dataset 11
python MC_410T_MultiCard\delivery\tools\compare_ring_recon.py `
  build\ring_recon_out14 build\ring_recon_cuda_out14 360 360 40 --dataset 14
```

预期：acc/accW/归一化图最坏相对差均 < 1e-3，输出 PASS。

## 6. 参数与前端交互控件的对应关系

查看器命令行参数是前端控件的临时替身；正式前端将直接填充
`RingReconCudaConfig`（见 `src/RingRecon/ring_recon_cuda.h`），
该结构已包含 MATLAB 主脚本初始化全部参数：

| 查看器参数 | RingReconCudaConfig 字段 |
|---|---|
| `--id 11/14` | `dataNum`（实际采集由前端选择数据流） |
| `--grid-mm` | `gridSize` |
| `--block` | `alinesPerBlock` |
| `--engine cpu/cuda` | 引擎选择（前端后续固化/可选） |
| 固定值 | `sampDepth/daqHz/radius/coverageDeg/fovDeg/sysDelay[8][2]/...` |
