## FilteredDAS 滤波反投影

本次仅实现入口脚本的 pa2d_bandlimited_prefilter + 现有 DAS，不能等同于脚本另一 FBP 分支。
默认开启，Order=.5、Reference=5 MHz、Pass=40 MHz、Stop=60 MHz、PadFactor=4、BatchColumns=64。
主页面为独立“滤波反投影”复选框与四参数，专属高级窗口为补零倍数和每批 A-line 数。
高级/父草稿、取消/应用、完整默认保存与恢复沿用时变低通相同事务规则，两者独立。
JSON 为 ring.filteredDas；INI 为 RingConfigDialog/Defaults 下 filteredDas 前缀。缺省对象默认开启；
对照工具须显式发送 enabled=false。坏 INI 整体提示并回退完整 disabled 安全快照，不改写原记录。

每个物理通道/波长按自己的实际裁切长度 nt 准备响应，nfft=nextpow2(PadFactor*nt)，
对称零填充后整条线 FFT，乘半阶幅度及负相位的带限响应，DC/Nyquist 置零，逆变换后裁回同一位置。
single 响应先 cast 为 float；CPU double FFT 的最终 float 路径通过 MATLAB single 独立容差验证。
无跨线/卡/波长信号混合，不恢复已被前端滤去的频率，不新增 ReconDepth 截断。
原服务展平/append 的 nt 及几何映射原样保留；新响应不使用展平后的平均 nt 推导频轴。
WL2 历史只保存已经完成两项处理的线，复用时不再滤波；任何线/批失败不提交 CUDA 或部分历史。

新核独立实现 radix-2 FFT，没有抽取或修改已审核时变低通核，无第三方依赖。
配置缓存全部长度的响应/FFT 计划，共享按 BatchColumns 分配的多列工作区，每批重写信号，关闭时完全跳过。
资源上限：nfft<=262144，工作区<=256 MiB，全部计划<=128 MiB（不含容器/allocator 固定开销）；
每配置超限明确拒绝，不缩小 PadFactor 或批数；原子准备时旧/新配置最多并存两份，滤波核动态存储最坏为 768 MiB。
开启时按实际采样率/采集深度/DelayCut 重建缓存。
Stop 超过当前有效声速/网格的空间 Nyquist 时给非阻断提示；时间 Nyquist 仍严格拒绝。
服务配置先准备两项增强再整体替换，原启动拒绝修复保持，真实主窗口测试覆盖新参数拒绝和 resident 服务。
