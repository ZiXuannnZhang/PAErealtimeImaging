# A4 门评估 — next_fast_len（2/3/5 混合基 FFT）

任务文档 §4 预注册的门：**仅当**预算数据显示大 sampDepth 场景（12330 点 → 16384，
填充浪费 33%）使 A3 之后 FFT 段仍占每 A-line 预算的显著份额、且 12330 点 freq
仍接近或超过 1990 µs 预算时实施。

## A3 后实测数据（mingw-release，实录/合成口径同任务 1，中位）

```text
每 A-line 可用预算（任务 1 §8，block=200、T_arr=5.0s 设计节拍）: ≈1990 µs

len 3830（默认配置，fftSize=4096，填充浪费 7%）:
  freq = 258-265 µs/A-line（两轮 258.0/264.6 中位）
  both = 270-291 µs/A-line
  FFT 段占预算 = 264.5/1990 ≈ 13.0%（>10%——预注册的"低于 10%"子判据不成立，
  但该子判据只用于描述 3830 场景，不是混合基的实施触发条件）

len 12330（大 sampDepth 场景，fftSize=16384，填充浪费 33%）:
  freq = 1294.8-1339.6 µs/A-line
  占预算 = 1295/1990 ≈ 65-67%  →  未接近、未超过 1990 µs 实施门
```

## 混合基的潜在收益（若实施）

```text
next_fast_len(12330) = 13500（2²·3³·5³，5-smooth）
  FFT 点数 16384 -> 13500：变换量 -17.6%，填充浪费 -17.6%
  freq 段估计 1295 -> ~1070 µs（省 ~225 µs/A-line，约占预算 11%）
next_fast_len(3830) = 3840（2^8·3·5）
  4096 -> 3840：仅省 6.25% FFT 时间 ≈ 16 µs/A-line ≈ 0.8% 预算
```

## 结论

**A4 不实施**。依据：
1. 实施触发条件（12330 点 freq 接近或超过 1990 µs 预算）在 A3 后不成立
   （实测为预算的 65-67%，余量 650+ µs/A-line）；
2. 混合基在 12330 场景的最大理论收益（~225 µs/A-line）不改变任何结论
   （65% -> 54%），却引入 2/3/5 混合基实现、独立对拍与计划缓存复杂度；
3. 3830 默认场景填充浪费仅 7%，A3 后 FFT 段 13% 预算占比对实时性不构成约束；
4. 优化任务文档 §4 的预期（"默认配置 3830→4096 仅浪费 7%，A3 之后大概率不需要"）
   与实测一致。

若未来出现更大的 sampDepth（如 ≥20000 点，16384 不再够用）或预算口径收紧，
按本评估的剩余空间重开门。
