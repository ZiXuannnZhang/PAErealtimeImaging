- 对 `freqA`、`freqB` 使用同一套系数，各自独立滤波；
- 逐 A-line 独立：一次滤波的输入是一条通道在一个 TriggerGroup 内的完整采样序列；

- 16-bit 与 32-bit 位宽、不同 `sampleCount` 的帧都要能处理；

  不得使用 `SAMPLE_FREQ_HZ`、`SAMPLE_INTERVAL_NS`、`DIFF_SAMPLE_RATE_HZ`
  或 `FREQ_SCALE_KHZ` 参与任何滤波换算。

### 3.3 滤波器结构与设计

高通与低通各自是一个独立的 Butterworth 数字滤波器，以二阶节（SOS）级联表示，
滤波采用前向 + 后向（filtfilt）执行得到零相位结果。

设计步骤（高通、低通分别执行，参数见 3.4）：

1. 采样率 `fs = FPGA_ADC_FREQ_HZ`。给定截止频率 `fc`，计算预畸变模拟截止
   `Ω = 2 · fs · tan(π · fc / fs)`。
2. 构造 N 阶模拟 Butterworth 低通原型，极点为
   `p_k = Ω · exp(j · π · (2k + N − 1) / (2N))`，`k = 1 … N`。
   - 低通：使用该原型直接得到 `H_lp(s)`，N 个零点位于无穷远；
   - 高通：由同一原型做谱变换 `s -> Ω / s` 得到 `H_hp(s)`，即 N 个零点位于 `s = 0`。
3. 双线性变换 `s = 2 · fs · (z⁻¹ 用 1/z 代入的标准形式)`，得到数字传递函数 `H(z)`。
4. 增益归一化：低通在 DC（z = 1）处增益为 1；高通在 Nyquist（z = −1）处增益为 1。
5. 将 `H(z)` 分解为二阶节级联，每节按 `[b0 b1 b2 a0 a1 a2]` 存放并归一化到 `a0 = 1`；
   N 为奇数时含一个一阶节（其 `b2 = a2 = 0`）。
6. 单向滤波的节内实现采用直接 II 型转置结构，按节顺序级联。

两路都启用时的执行顺序：先高通、后低通；每一路各是一次完整的前向-后向滤波，
即高通的输出作为低通的输入。任一路未启用则整路跳过（不做系数设计，不做运算）。

### 3.5 filtfilt 执行

对每一路，输入为长度 `n` 的单条 A-line 序列：

1. 端部延拓：奇对称反射，两端各延拓 `L = 3 × N` 点（`N` 为该路阶数）：
   - 左端第 `k` 点（`k = 1 … L`）取 `2 · x[0] − x[k]`；
   - 右端第 `j` 点（`j = 1 … L`）取 `2 · x[n−1] − x[n−1−j]`；
   - 若 `n ≤ L`，取 `L = n − 1`；
   - 若 `n < 2`，该路对本序列直接原样返回。
2. 正向滤波：延拓后的序列经 3.3 的 SOS 级联滤波一次，滤波器初始状态置零。
3. 将上一步结果时间反转，再经同一 SOS 级联滤波一次，滤波器初始状态置零。
4. 将结果时间反转，截去两端各 `L` 点，得到长度为 `n` 的输出，写回目标缓冲。

高通与低通串联时，对每一路各执行一遍上述 4 步。

禁止使用跳过起始样本、固定样本偏移、system_delay 截断，或任何依赖样本位置的
跳过 / 截断规则。

### 3.6 参数下发、缓存与生效时机

- 滤波参数属于 Frontend Preprocessing 配置。禁止写入 `RingReconCudaConfig`、

## 7. Required tests

新增滤波测试（并入 `frontend_preprocessor_test` 或新建独立测试目标，二选一并说明），
至少覆盖以下检查项：

1. 双路均停用：输出序列与输入序列逐点一致。
2. 仅高通启用 / 仅低通启用 / 两路同时启用：三条路径都可执行，输出长度与输入一致。
3. 零相位：对称输入序列滤波后的输出关于序列中心对称。
4. 逐 A-line 独立：同一系数下，两段序列分别滤波的结果与拼接后整体滤波得到的
   对应片段一致，差异在浮点舍入量级。
5. 端部延拓：延拓长度为 `3 × 阶数`，两端按奇对称反射规则取值；
   用可复算的已知序列断言实际采用的延拓与截取规则。
6. 短序列保护：`n < 2` 与 `n ≤ L` 的输入行为确定、不崩溃、输出长度与输入一致。
7. 保存隔离：滤波只改写 frontend clone；raw 对象在滤波前后逐点不变。
8. 同源分发：DisplayBuffer 与 Ring sink 收到同一个 frontend clone
   （沿用既有 one-clone / two-consumers 断言方式）。
9. 生效时机：变更配置后，下一处理帧使用新系数；已在处理中的帧不被中断。
10. 系数设计计数：同一配置下连续处理多帧时 `filterDesigns` 不增长；
    配置变更一次则增长一次；`filterConfigVersion` 同步递增。
11. 并发更新：UI 线程更新配置与 worker 处理并发执行时无数据竞争（压力用例或
    测试探针均可，需能被重复执行）。
12. 参数校验：截止频率越界、阶数越界、两路启用时低通截止 ≤ 高通截止，
    三种情况下配置不被更新。
13. 异常包含：滤波实现抛出的异常不逃逸出 worker 线程，计入既有 `exceptionDropped`
    且线程继续处理后续帧。

同时更新受接口变化影响的现有测试，至少包括 `frontend_preprocessor_test`
与 `data_processor_imaging_isolation_test`。
