## 0. 总约束

- 两开关全关路径在**任何阶段、任何提交**都必须与 main 构建的输出 **memcmp 逐位一致**（R4）；
- 两算子的数学定义（`g(t) = p − t·p′`、`H(f) = 1 + (Hmax−1)·exp(−(f/fc)^order)`）不得改变；优化只改变计算方式与速度；
- 不改 `RingReconCudaConfig` ABI；不改 raw/save/publish/前端显示路径；
- 每阶段一个（或一组显式关联的）commit，push 前跑完该阶段验收清单并附证据。

## 1. A1 边界方法固化（随首个实现 commit 一并提交）

更新 `docs/环形重建增强.md`「信号顺序」一节：

1. 写明当前填充方式是**整样本对称反射延拓**（不是补零），理由：C₀ 连续、延拓后 DFT 为实、乘实增益保持零相位；对比补零会导致低频提升核在边界产生起振/振铃伪迹；
2. 写明反射拼接点存在 C₁ 斜率翻转及其影响面（低频提升核时域越长越明显）；
3. 奇延拓作为可选替代的评估结论：仅当预算任务的图像 A/B 显示可见边缘伪迹时，才新增 `boundaryMode` 配置实现之；默认不加配置面。

## 2. A2 调用开销消除（无语义变化，先做）

`RingSignalEnhancer::Impl` 内预分配并复用缓冲：

- `work`（double，长度 = sampleCount 上限）与 `values`（complex，长度 = fftSize 上限）改为成员缓冲，按 config 变更时重置；消除当前每根 A-line 的 2 次堆分配与 `plans` unordered_map 查找热路径开销（计划缓存保留，按 sampleCount 键控）；
- 不改变任何计算次序与舍入：本阶段验收要求 on 模式输出与 A2 前**逐位一致**。

验收清单：`ring_signal_enhancer_test` 全过；`ring_enhancer_bench` 重跑对比（同矩阵）记录加速比；Layer 2a 的 `branch-off`/`branch-both` 各复跑 ≥3 圈，`off` 逐位一致、`both` 逐位一致、耗时下降幅度记录。

## 3. A3 实 FFT 快速路径（核心优化）

反射延拓后信号为实且对称 → DFT 为实。用标准 pack-trick 将 N 点实 FFT 化为 N/2 点复 FFT（复用现有 radix-2 引擎）：正向 2×、逆向上（逆变换输入频谱实对称 → 输出实对称，同享 2×），FFT 算力合计约降至 1/4。

实现要点：

- 仅替换 `applyFrequencyGain` 的变换实现；导数补偿（时域中心差分）不动；
- freqGain 数组改为半谱（k = 0..N/2）寻址，DC 与 Nyquist 项单独处理；
- 复用 A2 的预分配缓冲（尺寸减半）。

**数值口径（预先写死）**：

- 双精度内与本实现前偏差 ~1e-16 相对量级；cast 到 float 后目标为逐位一致，**允许个别样本 ±1 ULP**（理论期望每圈约 0.03 个样本落在 float 舍入边界）；允许的差异必须在证据中列出（样本号、前后值）并经审查确认属舍入边界；
- 全关路径逐位一致不受影响（early return 未触及）；
- 语义测试全部保留：常数→×Hmax、斜率抵消、H(f) 单调性、off 恒等。

验收清单：新增 `ring_enhancer_rfft_parity_test`（或并入既有测试）：随机实信号 + 实录 A-line 上，新旧路径 float 输出 max 差异统计（期望 0，容忍 ±1 ULP 列表）；`ring_enhancer_bench` 同矩阵重跑（预期 FFT 段 ≈4×，整体 ≥2×）；Layer 2a 复跑（`both` ≥3 圈）+ 逐位帧比较（按上述口径）；耗时会签预算任务的「每 A-line 可用预算」。

## 4. A4 next_fast_len（有门，默认不做）

仅当预算数据显示大 sampDepth 场景（如 12330 点 → 16384，填充浪费 33%）使 FFT 段仍占每 A-line 预算的显著份额时实施：引入 2/3/5 混合基 FFT，`next_fast_len(3830) = 3840`（2^8·3·5）。默认配置 3830→4096 仅浪费 7%，A3 之后大概率不需要。

- 实施则新增独立对拍单测（混合基 vs radix-2 全复数路径，双精度 1e-12 相对容差）；
- 计划缓存与 A2/A3 兼容（按 sampleCount 键控）。

## 5. A5 下沉/并行（有门，仅在预算判据命中后立项）

预算任务 §8 判据命中（release 复核后仍命中）才实施，二选一：

- **A5(a) CPU 并行**：QtConcurrent fixed-size pool 对块内 A-line 的 {preprocessBlock + enhancer.apply} 并行；必须保持 wl1/wl2 交错归属与 wl2 跨块对齐逻辑的次序语义（对齐消费的是处理后的列，需证明无竞态）；改动 ImagingSvc 结构，独立审查后实施；
- **A5(b) CUDA 下沉**：cuFFT batched rfft（整块 A-line 一次 plan）+ 导数核；经 `ring_recon_cuda` DLL **新增导出函数**承载（不改 `RingReconCudaConfig` 结构，但 DLL 接口变化 → 按铁律 DLL/ImagingSvc/主程序/selftest/verify/viewer 同 commit 重建）；GPU 侧算子须与 CPU 侧通过同一对拍测试（双精度 1e-9 相对、float 口径同 §3）。
