# Ring 时变低通（实现候选，未实机/视觉验收）

本说明只描述 `codex/ring-timevar-lowpass-20261016`，不代表 canonical main 已接受。
旧双极与低频补偿的生产代码、配置传输、控件及默认值读取已移除；历史证据保留在 CODEX_REPORTS 与原分支。

生产顺序：既有前端高通→低通→Ring feed→服务完整 A-line 转 double→可选 STFT 时变低通→
既有 DBR 置零→限幅→DelayCut→WL2 跨块对齐→CUDA DAS。p1/p2 始终是裁切前的 1-based 采样点。
DisplayBuffer、raw publisher、FileSaver、CUDA ABI 与 SHM 布局不变。

主页面保留“重建增强”框，第一行是启用开关和“高级参数”；仅显示 fcMax、fcMin、p1、p2。
出厂快照：disabled，45/1 MHz，780/2000；高级默认 128、0.75、auto FFT、4、smoothstep。
高级窗口只更新父草稿；父应用/确定才提交，父取消恢复最近成功应用的滤波配置。
“设为默认”保存有效完整草稿，“恢复默认”读取已保存值；启动读取不清理或覆盖旧/坏 INI。
只有显式保存成功时移除旧 enhance 键。深度变化后启用配置重新校验，不静默钳制。

JSON 是 ring.timevarLowpass；10 个字段见 RingTimevarLowpassConfig.h。
INI 是 RingConfigDialog/Defaults 的 timevarLp 前缀，单位 MHz。
缺字段使用出厂字段；存在但类型/范围错误时拒绝整个快照。错误默认值回退完整 disabled 出厂快照并提示。
服务先解析、校验和准备计划，再替换配置与各通道延时；任一 A-line 失败时整块不提交 CUDA，也不提交部分 WL2 历史。

数值契约由 MATLAB R2023a / Signal Processing Toolbox 9.2 生成的 fixtures 锁定。
周期 Hann、完整帧（无边界补帧）、onesided FFT、幅度掩膜及 WOLA；iSTFT 长度不同则按时间轴线性插值、范围外为零。
任意合法 FFT 长度用原创 radix-2 / Bluestein 实现，无新增第三方依赖；不依赖 MATLAB 运行时。
每配置缓存窗、FFT plan、频域掩膜和工作区，每条线清空信号状态。关闭时直接 bypass。
新增 CPU 内核单独使用 -O2（GCC/Clang），保留 Debug 符号、无 fast-math；其余标准 preset 不变。

显式资源边界：窗/FFT 最大 16384；启用时采样深度最大 1048576；掩膜最多 8M doubles（64 MiB）。
超界明确拒绝，不缩小参数。低重叠组合保持 MATLAB 的小 WOLA 权重处理，不另造 padding。
