# 环形重建增强（未验收实现）

状态：实现候选，尚未实机验收，不代表 canonical main 已接受能力。

## 1. 功能边界

本实现只作用于环形扫描实时重建输入：

```text
ImagingSvc::processRingPulse
  -> ringrecon::preprocessBlock
  -> RingSignalEnhancer
  -> ring_recon_cuda_append_angles_radii*
```

包含两个独立信号域算子：

1. 低频补偿：
   ```text
   H(f) = 1 + (Hmax - 1) * exp(-(f/fc)^order)
   ```
2. 双极波形补偿：
   ```text
   g(t) = p_c(t) - t*d(p_c(t))/dt
   ```

固定约束：

- `lambda(t)=t`，不提供 `lambdaSlope` 参数；
- 不执行正整流，输出保持 signed DAS；
- 不修改 raw、保存、发布、前端显示或线性 `pa_recon_core` 分支；
- 不包含距离/介质传播补偿。

## 2. 配置

“环形扫描参数设定 -> 重建参数 -> 重建增强”：

| 参数 | 默认 | 含义 |
| --- | --- | --- |
| 启用双极波形补偿 | false | 执行固定 `lambda(t)=t` 的导数补偿 |
| 启用低频补偿 | false | 执行固定 `H(f)` 曲线 |
| fc(MHz) | 10.0 | 低频补偿转折频率 |
| Hmax | 2.0 | 零频最大增益 |
| curve order | 2.0 | 高频趋近 1 的曲线阶数 |

两项功能独立开关，可以分别 A/B。配置由 `RingEnhanceConfig` 承载，不扩展
`RingReconCudaConfig`，因此不改变 `ring_recon_cuda.dll` ABI。

## 3. 信号顺序

```text
DBR / 限幅 / DelayCut
-> H(f) 低频补偿
-> 中心差分 dp/dt
-> 乘 t 并翻转
-> signed DAS
```

H(f) 对完整 A-line 独立执行。生产实现采用反射延拓和 FFT/IFFT；两个波长共享同一组频域参数。时间零点为 DelayCut 后第一个保留采样点。

## 4. 与现有 DAS 参数的关系

- `Apodization` 仍是 A-line 角度窗；
- `距离权重指数` 仍是 DAS 几何距离权重；
- `MinDistance` 仍是距离权重分母的数值下限。

三者不与 H(f) 或导数补偿合并，也不承担低频/深度补偿语义。
