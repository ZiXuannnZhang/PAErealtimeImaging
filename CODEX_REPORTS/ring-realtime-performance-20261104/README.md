## 实现

- 亚采样校正抽为独立 `RingFractionalDelay.cpp`，逐文件-O2、double计算、缓存当前FFT长度的位反转/旋转因子/工作区及当前相移频响。保持原nextpow2(N+64)、正频Nyquist、逆归一化及最后float舍入；零偏移严格旁路。
- FBP模式启用STFT时自动使用双精度批量cuFFT。CPU原实现继续设计窗口、mask、归一化及插值映射；不改变滤波参数、长度分支、尾零和处理次序。GPU输出按固定frame顺序WOLA，不使用并行原子浮点累加。
- GPU计划/缓冲按配置准备并执行零批预热，复用有界批次（最多128条、频谱区不超过64 MiB）。准备失败auto回退CPU并记录日志；运行失败停止成像，整块预处理成功后才更新FBP，不发布半更新波长对。
- 保留电干扰模板、跨块中值、物理圈隔离、原始数据保存与原界面参数。新增诊断字段报告实际后端及预处理/FBP累加耗时；诊断工具可强制CPU作对照。
- 修复自检工具把cppzmq非阻塞发送空返回值误判为成功的问题；FBP测速先等待服务预热确认。

GPU时变低通当前用于改进FBP路径，DAS仍沿用原CPU时变低通。未降低网格精度、重叠率或浮点精度。
未进行第三阶段GPU预处理与FBP直接衔接：两通道最重已测组合具有足够计算余量，用户随后要求最小检查、快速交付。

## 两通道最小性能对照

用户条件：双波长合计40 Hz、250 MS/s、7500点，2通道。测试使用36 mm FOV、10 µm网格、
每块10触发、扇区拼接/5°羽化、半径6.48 mm、7.5 mm圆层、1490/1540 m/s、
DelayCut 448/464、DBR mask375、工厂STFT开启、两波长各通道固定校正+0.375采样。
同一新自检工具分别驱动旧交付服务与新服务。各21块，排除首块，全部20个稳态样本保留。
GPU为RTX4060 Laptop 8GB；主应用Qt6.8/MinGW13.1 Debug，STFT及校正源文件各自-O2；CUDA12.8 Release。

## 构建与实机包

先运行 `delivery/build_ring_fbp_cuda.cmd`，再运行 `delivery/build_mingw_debug.cmd`。
新增运行库为CUDA12.8自带的 **cufft64_11.dll**；既有线性链路的cufft64_12.dll保持原来源，两者并存。
必须解压完整包，不单独替换DLL。使用改进FBP并按现场需要开启时变低通及加载真实校正，正常配置自动选择GPU后端。
不要将本次合成+0.375采样测试值作为实机标定值。包内不写入伪造标定，也不改变原生用户INI。
下一步现场重点验证两通道40Hz的图像、校正参数及真实数据连续运行；8通道吞吐和更长时间压力测试本次未验收。
