# 发现相关配置项说明

所有配置位于 INI 文件（注册表镜像键 HKCU\Software\MC410T\MC410T_Receiver 同名节），程序首次运行后自动生成缺失键。超出范围或非数字的值会回退到默认值，并在 UI 日志中记录"发现参数已规范化"。

## 新增：Discovery 节

| 键 | 默认 | 范围 | 说明 |
| --- | --- | --- | --- |
| Discovery/AckWindowMs | 2000 | 500–5000 | 每轮等待 60 字节 CONFIG 确认的窗口时长（毫秒）。 |
| Discovery/MaxAttempts | 5 | 1–10 | 最多向未确认候选重发 CONFIG 的轮数。 |
| Discovery/FinalGraceMs | 500 | 0–2000 | 最后一轮之后继续接收晚到确认的宽限时长（毫秒）。 |
| Discovery/IcmpTimeoutMs | 150 | 50–1000 | ICMP/ARP 可达性诊断探测的超时（毫秒）。结果仅用于诊断与发送顺序，不决定卡身份。 |

总发现等待上限约为 AckWindowMs × MaxAttempts + FinalGraceMs（默认约 10.5 秒），另加少量 socket 建立与发送开销。

## 沿用的既有配置

| 键 | 默认 | 说明 |
| --- | --- | --- |
| NetworkParams/ScanBaseIP | 192.168.0.2 | 动态发现候选范围起始 IP。 |
| NetworkParams/ScanIPCount | 32（上限 64） | 候选数量；1–254 边界内的数值顺序生成候选。 |
| NetworkParams/LocalBindIP | 空 | 控制 socket 本地绑定 IP。为空时通过 Windows GetBestRoute2 自动选择本地源地址；配置的值必须是本机 IPv4 且不得与候选目标相同。 |
| AcquisitionParams/NCards | 4 | 仅在 CONFIG-ACK 动态发现成功后按确认卡数回写；发现失败时不修改。 |

## 行为约定

1. 自动模式下只有返回 60 字节 CONFIG 确认的候选 IP 才会成为采集卡；ICMP/ARP 可达与 18 字节就绪报文只是诊断证据。
2. 本机所有 IPv4（含 down 接口与回环地址）在发现开始前被排除，不会收到 CONFIG。
3. 发现期间临时占用 UDP 8000 端口，发现结束（成功、失败或取消）后立即释放；若 8000 被其他程序占用，发现直接失败并给出 WinSock 错误码，不会启动正式监听。
4. 发现参数在点击"开始监听"时取一次快照，发现期间采集时间/延时输入框被锁定。
5. --target-ips 显式目标旁路行为保持不变。
