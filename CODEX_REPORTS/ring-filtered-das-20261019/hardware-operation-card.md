# 两增强联合候选实机操作卡

仅使用最终包 `git-receipt.txt` 所列 exact SHA 及同包 DLL。先保存现场配置；软件自动测试使用隔离 INI，
本卡由用户在真实采集链执行。视觉、采集链和 T_arr 在执行本卡前均为 UNVERIFIED。

旧双极/低频补偿已移除。时变低通默认关闭：45/1 MHz、p1/p2=780/2000（裁切前 1-based），
高级 128 / .75 / auto FFT / 4 / smoothstep。滤波反投影默认开启：Order=.5、Reference=5 MHz、
Pass=40 MHz、Stop=60 MHz；专属高级 PadFactor=4、BatchColumns=64。

在同一场景、采集参数、通道、DelayCut、几何和显示尺度下依次执行：

|组合|时变低通|滤波反投影|
|---|---|---|
|A|关闭|关闭|
|B|开启|关闭|
|C|关闭|开启|
|D|开启|开启|

每次切换先停止实时成像，在“环形扫描参数设定 → 重建参数 → 重建增强”应用完整配置，
再启动；记录实际生效值、服务重启/ready 与 exact SHA。保持显示尺度一致，不做自动 gain matching。
分别保存双波长图像和诊断记录，观察首尾结构、相位变化、伪影、空间采样提示和幅值变化，
不能以“更亮”替代视觉接受。前端时域/频域、raw 文件及 publisher 应保持原契约。

在各组合检查：

1. 当前实际 2 通道几何及目标 4/8 通道、N5000/7500；不同通道/波长 DelayCut 后长度。
2. 各自高级窗口取消/确定、父取消/应用/确定；完整设为默认、恢复默认、重启程序、首次启动与服务重启。
3. 停止后新一轮清洁启动；多卡双波长 WL2 跨块对齐无重复滤波或跨轮历史。
4. count-boundary cap 后 Ring 冻结且前端持续刷新；timeout 后旧轮保存/reset/stale 顺序及下一轮清洁启动。
5. 记录真实块到达周期 T_arr、完整块处理耗时、积压/丢块及长期峰值内存。

图像、日志、采集场景和结论绑定包内 SHA、依赖 hash 与完整参数。时变低通与 FilteredDAS 的接受分别记录，
联合接受后再决定是否合并 main；本任务不自动合并。前端已滤去的频率不能靠本模式恢复。
