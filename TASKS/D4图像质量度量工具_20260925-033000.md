## 3. 指标定义规格（**必须逐条照此实现，不得自行改口径**）

对给定重建图 `I(x,y)`（浮点、线性、**未做任何显示拉伸**）与已知目标位置：

| 指标 | 定义 |
|---|---|
| **轴向/切向分辨率** | 过目标峰值点沿指定方向取线剖，求 −6 dB（半高）全宽；线性插值过零点取半高交点；给出 mm。方向以**相对环心的径向/切向**定义，不得用图轴近似 |
| **位置误差** | 重建峰值坐标与已知真值坐标的欧氏距离，mm |
| **CR（对比度）** | `20·log10(peak / mean_background)`，dB；背景区 ROI 需显式给出且不含目标与伪影 |
| **gCNR** | 按 Kempski 等, *Biomed. Opt. Express* 11(7), 3684 (2020) 口径：`gCNR = 1 − ∫ min(pdf_T, pdf_B)`，`pdf_T`/`pdf_B` 为目标/背景 ROI 的归一化灰度直方图；直方图 bin 数与灰度归一化方式须写明 |
| **背景噪声** | 背景 ROI 的 std（绝对）与相对峰值的比值 |
| **CNR** | `|mean_T − mean_B| / std_B`（目标 ROI 均值 vs 背景 ROI 均值/标准差） |

**必选附加项（R1 判别性守卫）**：
**双波长比值守卫** —— 输入两张**同几何**重建图 `I_1`（wl1）、`I_2`（wl2），断言
`I_1/I_2` 在指定 ROI 内为常数（相对标准差 ≤ 容差），且该常数等于输入信号的幅值比。
**这条测试会直接判死「逐图归一化/整流」类方案。**

## 4. 具体要求

1. **ROI 定义显式**：目标 ROI、背景 ROI 的形状与选取规则必须参数化并在输出中打印，
   不得硬编码到具体体模。
2. **不做任何隐式归一化**：度量在**输入的原始线性数值**上计算。若调用方传入已归一化图，
   须在输出中标注。
3. **不调用生产函数充当参考**：度量必须独立实现。
4. **单元自检**：对构造的解析用例（例如已知宽度的高斯峰 + 已知幅值比的双波长图）
   断言指标算得对；负例（例如把两波长各自峰值归一化后）应使比值守卫**失败**。
5. **输入格式**：明确支持的输入（原始数组 / 简单二进制 / CSV），并在返回中写清。
