## 4. Problem / Evidence

## 7. Recommended Design / 数据位置与后端职责

生产顺序固定为：

~~~text
既有 FrontendPreprocessor 高通→低通
  ├─ DisplayBuffer（原样保持）
  └─ Ring feed → RingBlockAssembler → ImagingController → ImagingSvc
       round admission / 原有 stale barrier
       → 按通道/触发识别波长，完整 A-line 转 double 向量 d
       → [启用时] STFT 时变低通(d, Fs, config)
       → 原 ringrecon::preprocessBlock
           去直达波置零 → 限幅 → DelayCut
       → 原 WL2 对齐 / 几何映射 → CUDA DAS
~~~

优先在 ImagingSvc 现有 d 构造之后、preprocessBlock 调用之前接入新滤波，保留 preprocessBlock 的既有默认调用行为。去直达波必须在新滤波之后，避免滤波重新填充已置零区；限幅也继续在滤波之后生效。

建议新增 RingTimevarLowpassConfig、RingTimevarLowpass 独立配置和 CPU 算法类。配置校验/JSON 编解码共享 helper 可供 UI、controller、service、测试使用。算法核心与 Qt/UI 解耦，double 中间运算，最后仍由既有 preprocessBlock 转成 float。

每个 svc configure 使用完整配置快照；先完成类型/范围/采样深度校验和所需 plan 准备，再提交状态。非法配置通过现有非致命错误通道返回，不能留下“部分新、部分旧”配置，不能自动关闭滤波伪装成功。运行中 A-line 失败时不得把同一块已完成一部分的内容提交 CUDA，也不得混用滤波/未滤波线；记录清晰错误，保持轮次 ownership 与已有失败处理边界。

## 8. 数值移植契约

以附录的实际运算和 MATLAB 参考输出为准。它是短时 FFT 的时频幅度掩膜，不是直接对每个时刻设计 IIR，也不是把幅度响应平方的 filtfilt。

- 周期 Hann 窗；L=round(WindowLength×OverlapRatio)，再 min(L,WindowLength-1)，hop=WindowLength-L。
- FFTLength 自动时取不小于 WindowLength 的最近 2 次幂；显式值不能静默向 2 次幂修正，需支持合法的非 2 次幂及奇数长度。
- 正向 onesided STFT、原始帧中心时间 T、samplePosition=T×Fs+1、频率 F 与 MATLAB 对齐。
- u=clamp((samplePosition-p1)/(p2-p1),0,1)；smoothstep 为 q=3u²-2u³，linear 为 q=u。
- fc=fcMax-(fcMax-fcMin)×q；H=1/sqrt(1+(F/fc)^(2×FilterOrder))。逐帧乘复谱，不改相位。
- iSTFT 的共轭对称、FFT 归一化、窗与重叠相加方式、首尾区间、返回时间轴需与 MATLAB 实测一致。不能自行加反射延拓、补全尾帧或“修复”边缘。
- 必须保留原参考的长度分支：返回长度等于 N 时直接取 yTemp；不等时按 tTemp 对原 (0:N-1)/Fs 做 linear 插值，范围外为 0。不能统一改成截断、补零或按数组下标对齐。
- 先用 MATLAB 小样本导出 F/T/fc/H/yTemp/tTemp/y，钉定帧网格、奇偶窗和端点行为，再完成 C++；不能用另一个 C++/Python 同构实现充当独立 oracle。
- 生产不生成诊断图，不保留 Plot/doPlot/绘图分支，也不为每条线保存 info.H 等诊断矩阵。info 仅供数值验证工具使用。

外部语义参考：
[MathWorks stft](https://www.mathworks.com/help/signal/ref/stft.html)；
[MathWorks istft](https://www.mathworks.com/help/signal/ref/istft.html)。
公开文档说明 STFT 返回帧中心时间、iSTFT 默认使用 WOLA；首尾与具体版本行为以附录函数在记录版本的 MATLAB 实测输出锁定，不靠记忆补写。

### 9.3 校验与有效域

UI、默认值读入、controller/服务端共用同一校验规则；现有 QSettings/JSON 缺键回退与存在但非法必须区分。

- 所有数值有限，0<fcMin<=fcMax<=Fs/2。

## 附录 A：去 Plot 的 MATLAB 数值参考

以下仅为任务规格内嵌的可复制 reference，不是向 task-docs 提交生产实现。执行代理将其提取到实现分支的 tests/reference/timevarLowpassSTFT.m，用于 MATLAB fixture 导出；生产程序不依赖 MATLAB。

相对上述原始文件仅移除注释/空白、Plot 参数及 doPlot/绘图块；首列 STFT 未使用的 S0 改为 ~，其余数值语句保持。基础参数由调用者明确传入，vardata 传 {} 即采用高级默认；不得把本函数的参数检查误认为四个基础默认已在函数内部定义。

~~~matlab
function [y, info] = timevarLowpassSTFT(x, Fs, fcMax, fcMin, p1, p2, vardata)
if ~ismatrix(x)
    error('输入 x 必须为二维矩阵。');
end
if ~isreal(x)
    error('当前函数只针对实数时域信号设计。');
end
if isempty(x)
    error('输入 x 不能为空。');
end
numSamples = size(x, 1);
numChannels = size(x, 2);
if Fs <= 0
    error('Fs 必须大于 0。');
end
if fcMax <= 0 || fcMax > Fs/2
    error('fcMax 必须满足 0 < fcMax <= Fs/2。');
end
if fcMin <= 0 || fcMin > fcMax
    error('fcMin 必须满足 0 < fcMin <= fcMax。');
end
if ~isscalar(p1) || p1 ~= round(p1)
    error('p1 必须为整数采样点位置。');
end
if ~isscalar(p2) || p2 ~= round(p2)
    error('p2 必须为整数采样点位置。');
end
if p1 < 1 || p1 > numSamples
    error('p1 必须位于 [1, size(x,1)] 范围内。');
end
if p2 < 1 || p2 > numSamples
    error('p2 必须位于 [1, size(x,1)] 范围内。');
end
if p2 <= p1
    error('必须满足 p2 > p1。');
end
t1 = (p1 - 1) / Fs;
t2 = (p2 - 1) / Fs;
p = inputParser;
addParameter(p, 'WindowLength', 128, ...
    @(v) isnumeric(v) && isscalar(v) && v >= 2);
addParameter(p, 'OverlapRatio', 0.75, ...
    @(v) isnumeric(v) && isscalar(v) && v >= 0 && v < 1);
addParameter(p, 'FFTLength', [], ...
    @(v) isempty(v) || ...
    (isnumeric(v) && isscalar(v) && v >= 2));
addParameter(p, 'FilterOrder', 4, ...
    @(v) isnumeric(v) && isscalar(v) && v > 0);
addParameter(p, 'Transition', 'smoothstep', ...
    @(v) ischar(v) || isstring(v));
parse(p, vardata{:});
winLength    = round(p.Results.WindowLength);
overlapRatio = p.Results.OverlapRatio;
nfft         = p.Results.FFTLength;
filterOrder  = p.Results.FilterOrder;
transition   = lower(string(p.Results.Transition));
if winLength > numSamples
    error(['WindowLength 不能大于信号的时间采样点数 ', ...
           'size(x,1)。']);
end
win = hann(winLength, 'periodic');
overlapLength = round(winLength * overlapRatio);
overlapLength = min(overlapLength, winLength - 1);
if isempty(nfft)
    nfft = 2^nextpow2(winLength);
else
    nfft = round(nfft);
    if nfft < winLength
        error('FFTLength 必须大于或等于 WindowLength。');
    end
end
[~, F, T] = stft( ...
    x(:,1), ...
    Fs, ...
    'Window', win, ...
    'OverlapLength', overlapLength, ...
    'FFTLength', nfft, ...
    'FrequencyRange', 'onesided');
numFrames = length(T);
samplePosition = T .* Fs + 1;
u = (samplePosition - p1) ./ (p2 - p1);
u = max(0, min(1, u));
switch transition
    case "smoothstep"
        q = 3 .* u.^2 - 2 .* u.^3;
    case "linear"
        q = u;
    otherwise
        error('Transition 只能设置为 smoothstep 或 linear。');
end
fc = fcMax - (fcMax - fcMin) .* q;
fc = fc(:).';
Fcol = F(:);
H = 1 ./ sqrt( ...
    1 + (Fcol ./ fc).^(2 * filterOrder) ...
    );
y = zeros(size(x), 'like', x);
tOriginal = (0:numSamples-1).' / Fs;
for ch = 1:numChannels
    S = stft( ...
        x(:,ch), ...
        Fs, ...
        'Window', win, ...
        'OverlapLength', overlapLength, ...
        'FFTLength', nfft, ...
        'FrequencyRange', 'onesided');
    Sf = S .* H;
    [yTemp, tTemp] = istft( ...
        Sf, ...
        Fs, ...
        'Window', win, ...
        'OverlapLength', overlapLength, ...
        'FFTLength', nfft, ...
        'FrequencyRange', 'onesided', ...
        'ConjugateSymmetric', true);
    yTemp = real(yTemp(:));
    tTemp = tTemp(:);
    if length(yTemp) == numSamples
        y(:,ch) = yTemp;
    else
        y(:,ch) = interp1( ...
            tTemp, ...
            yTemp, ...
            tOriginal, ...
            'linear', ...
            0);
    end
end
info.F = F;
info.T = T;
info.samplePosition = samplePosition;
info.fc = fc;
info.H = H;
info.p1 = p1;
info.p2 = p2;
info.t1 = t1;
info.t2 = t2;
info.WindowLength = winLength;
info.OverlapLength = overlapLength;
info.FFTLength = nfft;
info.FilterOrder = filterOrder;
info.Transition = transition;
info.NumSamples = numSamples;
info.NumChannels = numChannels;
end

~~~
