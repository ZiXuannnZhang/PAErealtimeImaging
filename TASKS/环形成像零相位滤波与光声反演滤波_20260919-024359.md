## 4. Problem / Evidence

生产链路：ImagingBypass → RingBlockAssembler → ImagingController → ImagingSvc → ring_recon_cuda。

已审查事实（基于 starting SHA）：

- `src/RingRecon/ring_recon_cuda.h` 中 filterLow/wLow/n1 与 filterHigh/wHigh/n2 为 reserved。环形 C++ 没有实际 Butterworth/filtfilt 实现。
- 历史命名 filterLow 实际指去除低频的高通；filterHigh 指去除高频的低通。
- 仓库 `RadiusCalibration/preprocess_ring_block.m` 和实时重建 MATLAB 参考使用 butter + filtfilt；历史参数为高通 0.4 MHz、低通 40 MHz、单程阶数 4，默认关闭。
- MATLAB 中第 301 行开始高通、system_delay+20 开始低通属于历史切片约定，不能无依据搬入生产。
- 线性 pa_recon_core 仅提供 DLL/接口，内部滤波无法审查，不作为本任务可复用实现。
- `src/RingRecon/ring_recon.cpp` preprocessBlock 当前主要执行 DBR 置零、削顶和 delayCut。
- CUDA 当前权重在未触发距离截断时近似为 Δθ·apod·cosα/d^q，快照无条件 acc/max(accW,epsilon)，accW 累加绝对权重。normalizeByW 目前不是有效开关。
- Apodization 按 append 块内 j/N 生成周期 Hann/Hamming 窗，而非全圈物理角度。
- 双声速沿直线路径计算分区长度并累计走时，不实现折射路径或界面透射幅度。

这些事实不代表新算法已获数值或实机验证。

## 7. Recommended Design

### 7.1 阶段 A：算法基准先行

先提交算法说明与独立数值参考，通过规划主代理数学/时间轴审查后再进入生产集成。此审查关口不授权提前选择没有依据的公式。

优先评估 MATLAB 注释所指的 `2[p(t)-t*dp(t)/dt]`。依据可靠光声文献与实际探测几何说明二维/三维近似、信号含义、积分测度、法向和距离权重、尺度因子及归一化。不能凭注释宣称严格二维 FBP；若假设与几何存在实质冲突，返回证据及修订建议。

反演 t 是与 CUDA 查询走时同坐标系的校准声学时间。核对 systemDelay 一基/零基含义、各通道/波长延时和 delayCut 开关。不得直接使用原始数组索引/fs，也不得无条件把 systemDelay 加回 t。写清 delayCut 两种状态的索引公式，用脉冲测试排除一采样点偏差。

双声速仅沿用现有直线分区走时近似。滤波器使用真实 daqHz，不用声速代替采样率，不按两个声速对同一 A-line 滤两次。不宣称严格非均匀介质解析反演。

冻结信号处理顺序和端点约定：用含启动强信号的合成信号及可获得真实数据比较滤波前强信号处理、延时裁剪与反演的顺序。避免对 DBR 硬置零阶跃直接求导；有效区间及延拓明确，排除样本不得泄漏回有效反投影区。不原样照搬 MATLAB 固定切片。将最终约定写入算法说明、参考实现和测试。真实数据缺失须标未验证，不伪造。

### 7.2 高通、低通零相位滤波

复用 Butterworth + 前后向零相位设计，不复用不可用的 C++ 实现。采用 double SOS 二阶节、稳态初始化、明确的奇对称延拓。每次配置设计并缓存系数，复用工作缓冲，不逐 A-line 重建设计。

高通先于低通。单独或组合开启均可。默认关闭；高通 0.4 MHz、低通 40 MHz、单程阶数各 4；首版阶数 1–8。

截止频率定义为单程 Butterworth −3 dB 点；前后向复合在该频率幅度约 0.5（−6 dB），界面提示明确。阶数指单程阶数。不声称与所有 MATLAB 版本的 filtfilt 端点逐点一致。

窗口不足延拓要求时报明确错误，不静默单向滤波或跳过。数值内部 double，保持现有 float 输出。导数离散方案固定并独立测试。

### 7.3 参数退役与反投影适配

删除距离指数控件、布局、config 采集和 defaults 读写。旧 distWeight 设置可留存但不读取、不清理其他设置。

后端旧可调指数片段保留为局部注释；不要注释整个反投影或移除必要几何项。反演关闭固定用旧默认 q=1 的等价计算；开启使用阶段 A 确定的公式权重及归一化，不再叠加任意指数。

为 ABI 保留的 distanceWeightExponent 字段标记不生效，旧 JSON 不能重新启用可调指数。不能用“q=0”冒充 FBP，也不能默认沿用 acc/accW。

MinDistance 保留默认自动值；Apodization 默认 none。本任务不顺带重写块内加窗，基准验收固定 none，其他组合单独测。

### 7.5 服务与 CUDA

逐线滤波首先在 ImagingSvc CPU 路径实现；实测不足再评估 GPU 化，不提前引入 FFT 依赖。明确复用 reserved 滤波字段的含义映射，反演选项不得借用不相关字段。

复用 CUDA 走时、插值、累积及 reset，只局部适配权重/归一化。配置结构若变更，必须版本化或增加兼容检查，避免 DLL/消费端布局错配。同步重建所需 DLL 与消费端；禁止旧 DLL fallback 掩盖构建失败。
