# 环形重建增强实时预算测试（H(f)/双极补偿）

> 日期：2026-09-27
> 性质：测量任务（只测不改生产代码），方法学沿用 `TASKS/D2重建链路实时预算基准_20260925-033000.md`，测量对象从 canonical main 的重建核扩展到增强分支的信号域算子。
> 待测实现分支：`codex/ring-reconstruction-enhancement-20260926-181824` @ `ee8049e`（父提交 = main `c95917f`）。
> 必读前提：`origin/main` 的 PROJECT_STATUS / REPOSITORY_BASELINE / BUILD_STANDARD；`TASKS/前提_UBP与FBP调研报告审核更正说明_20260925-033000.md`（R1–R4）；分支内 `docs/环形重建增强.md`。

## 1. 背景

分支在 `ImagingSvc::processRingPulse` 的逐 A-line 路径上新增 `RingSignalEnhancer`（挂点在 `preprocessBlock` 之后、`ring_recon_cuda_append*` 之前）：

- 双极波形补偿：`g(t) = p(t) − t·dp/dt`（t 单位秒，零点 = DelayCut 后首样本；中心差分；不整流）；
- 低频补偿：`H(f) = 1 + (Hmax−1)·exp(−(f/fc)^order)`（反射延拓 + FFT/IFFT，实增益，零相位）。

两算子均在 ImagingSvc 单线程内逐根 A-line 执行（每根 2 次堆分配 + 复数 FFT 对）。本任务实测其时间代价，回答规划侧四个问题，并为后续优化任务提供门槛数据。

## 2. 测试目标（四问，缺一不收）

1. 以 main 的实时成像时间为基准，分别开启「双极波形补偿」「低频补偿」「两者同开」后，成像时间各增加多少（分段 + 端到端）；
2. 依据预先写死的判据（§8），判断新增算子是否需要下沉到 CUDA；
3. 两个开关全关时，成像时间与图像输出是否与 main 一致（R4 的端到端版）；
4. 输出「每 A-line 可用预算 µs」，供优化任务的 A3/A4 门使用。

## 7. 全关一致性判据（目标四问之 3）

同一输入数据 + 同一配置（网格/块大小/圈数）下：

- **效果**：`branch-off` 与 `main` 的逐块帧文件做 `memcmp` 逐位比较，**必须 0 字节差异**；RingSHMObs 各计数器类别与数量一致。任何差异即接线缺陷：停止测试、修复分支、重新构建并重测（修复走分支新提交，报告新 SHA）。
- **时间**：`branch-off` 的 `avg_process_us` 与整圈 wall time 中位数须落在 `main` 多轮运行的 [min, max] 包络内（无系统性偏移）；超出即视为分支引入了全关路径的额外开销，须定位（如 JSON 解析、构造函数）并修复后重测。

## 8. CUDA 下沉判据（预先注册，不得事后调整）

设实测块到达周期 `T_arr`（Layer 2b 回放节拍下的块间隔；Layer 2a 自驱动节拍仅作参考）。判据全部满足 → **不下沉**：

```text
branch-both 的 median_process_us
  ≤ T_arr − main 的 median_process_us − 0.20 × T_arr        （余量判据）
且 (branch-both − branch-off) 的净增开销
  < 0.30 × (T_arr − main 的 median_process_us)              （占比判据）
```

任一不满足：先以 msvc2022-release 侧同口径复核（Debug -O0 会夸大 CPU 算子 3–10 倍）；release 侧仍不满足 → 判定需要下沉，转优化任务 A5(b)，并给出实测的「每 A-line 可用预算 µs = 0.70 × (T_arr − main median) / 每块 A-line 数」。
