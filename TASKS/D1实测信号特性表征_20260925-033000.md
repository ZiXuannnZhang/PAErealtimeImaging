## 4. 具体要求

对**每个物理通道 × 每个波长**分别给出：

1. **噪声底**：无回波（静默）区段的 RMS 与峰值；说明区段选取判据。
2. **有效带宽**：单条 A-line 及平均的功率谱，−3 dB / −6 dB 带宽与中心频率。
3. **脉冲形状**：主瓣宽度（−6 dB 与 −20 dB）、旁瓣比、过零结构；判断近似 N 形（双极）还是单极。
4. **启动 ring-down**：强启动干扰的幅度、衰减时间常数、残留拖尾长度（降到回波幅度 1% / 0.1% 的样本位置）。
5. **SNR 估计**：按明确定义（如回波峰值 / 噪声 RMS），写清口径。
6. **双波长一致性**：wl1 与 wl2 的噪声底、带宽、脉宽是否一致；不一致给出差异量。
   **不得用逐图归一化后再比较**（R1）。

**必须给出「导数可行性」判定**：按实测噪声底与带宽估计 `dp/dt` 的噪声放大程度，
给出 B2 低通截止的可行区间建议，或明确结论「导数型信号项在本数据上不可行」。
