## 0. 结论摘要（整改后）

1. **反演公式（维持，exp1 未改码重跑复核）**：信号组合 `b = 2p − 2t̃·∂p/∂t̃`（t̃ 用长度单位；等价于任务注释的 `2[p(t)−t·dp/dt]`，t 用秒），立体角权重 `dΩ₀ = dS₀·(n̂₀·(r−r₀))/r̃³`，输出 `(1/Ω₀)∮b·dΩ₀`（Xu & Wang PRE 71, 016706 (2005) Eq.(20)–(22)）。该式的精确性只对**完整 3D 闭合曲面 + 面内源**成立；紧支撑均匀球体内部重构误差 6.4e-8（exp1，本轮重跑复核通过）。**单环几何下是"单环平面 UBP"近似**，不宣称严格 2D FBP（§1.4）。
2. **时间导数整改（R1，exp2/exp3/exp5 已修复并加自动测试）**：9493962 版 `gradient(matrix, dt, 1)` 第三参数被 MATLAB 解释为 dim2（列/A-line）间距、单输出返回列向梯度——均匀盘导数为零、偏心目标为跨 A-line 差分。现改用 `timeDerivative.m`（dim 1 逐列、中心差分/端点单侧），四项断言 + 向量/矩阵路径一致性 + 导出参考向量影响检查全部通过（`test_time_derivative.m`）。**导出参考向量（filter_reference_vectors.mat 的 p′/b）由向量路径生成，未受矩阵误用影响**（重算相对差 3.2e-13/3.3e-13）。
3. **权重/归一化对照整改（R2，旧结论撤回）**：旧 "wrong" 对照只返回 acc 且被单参数 `normAcc` 自归一化成 sign(acc) 符号图（旧证据 discWrong cv=0、四目标峰值全为 1），其"位置误差 2.0–2.8mm、FWHM 恶化 ~3×"的结论**不可归因于权重，撤回**。整改后五模式因子分解（信号 × 权重族 × 归一化，共享核 `reconPairKernels.m`，accW 逐元素一致由 `test_fair_comparison.m` 验证）：均匀盘 CV = das 0.0153 / legacyW 0.0334 / **ubpD 0.0080** / ubpP 0.1084 / saP 0.0874；公平 legacyW 对照环内位置误差仅 0–0.2mm（非旧报告的 2–2.8mm）。**拟定配对（UBP 信号 + 立体角权重 + accW）在盘内平坦度上最优且物理依据明确，但点目标 CNR（9.2）低于 legacyW（15.6）、环外位置误差（1.13mm）高于 legacyW（0.28mm）——加权优劣互现，最终选择返回审查决策点（§4）。**

## 1. 反演算法依据

### 1.1 文献锚点（未改动）

- **主锚点**：M. Xu, L. V. Wang, "Universal back-projection algorithm for photoacoustic computed tomography," *Phys. Rev. E* **71**, 016706 (2005)。关键式（已取原文核对）：
  - Eq.(20)：`p0(b)(r) = ∫_{S₀} b(r₀, r̃=|r−r₀|)·dΩ₀ / Ω₀`，**`b(r₀,r̃) = 2p(r₀,r̃) − 2r̃·∂p(r₀,r̃)/∂r̃`**；
  - Eq.(22)：`dΩ₀ = dS₀·(n̂₀ᵢ·(r−rᵢ))/|r−rᵢ|³`，n̂₀ᵢ 指向源侧；Ω₀=4π（闭合面内点），平面 2π。
- 3D 精确式族：Finch, Patch, Rakesh, *SIAM J. Math. Anal.* 35, 1213 (2004)；Kunyansky, *Inverse Problems* 23, 373 (2007)。
- 2D（偶数维）精确式：Finch, Haltmeier, Rakesh log 核非局部式（转引自 Kuchment & Kunyansky 综述 Eq.(16)–(17)）。
- 综述：Kuchment & Kunyansky, *Eur. J. Appl. Math.* 19, 191 (2008)：3D 满足 Huygens 原理，**2D 不满足**（Green 函数有尾部）——2D 无局部 UBP 的物理根源。

### 1.2 精确性与验证边界

Xu–Wang UBP 的精确性要求：(a) 完整闭合曲面；(b) 源紧支撑在面内。因此：

- 本征模式（J 基/球 Bessel）不能用作验证数据（面外源）——该教训保留。
- 有效验证必须用紧支撑源 + 闭式前向。exp1（未改码，本轮重跑复核）：均匀球体、`C=1/Ω₀, b=2p−2r̃p′, dΩ=dS₀(n̂₀·(r−r₀))/r̃³` 下球内最大误差 **6.4e-8**；半常数变体偏差 0.5（被否定）。
- **球外残差（R5 措辞收敛）**：rho=4mm 处负值随求积分辨率收敛（nTheta/Nt = 4096/2¹⁵ → 65536/2¹⁹：−0.358 → −0.098 → −0.051）。该收敛行为**与数值离散误差解释一致；其确切机制（切点 1/r̃ 奇异性的求积处理、插值误差等的贡献分解）尚未隔离**。如需更强结论（如"确认为某单一伪影"），需增加独立网格加密或解析求积证据后再下——本阶段不下此结论，也不以此影响任何生产建议（球外区域本就标注未验证，§4.4）。

### 1.3 拟定反演公式（阶段 B 按审查结论实现）

对每个像素 x、每根 A-line i（探测器 x₀ᵢ = R·n̂₀ᵢ）：

```
dᵢ    = |x − x₀ᵢ|                          （直线距离，≥ minDist 保护见 §4.5）
cosαᵢ = (R − x·n̂₀ᵢ)/dᵢ                     （= −dotpᵢ/(R·dᵢ)）
ΔΩᵢ   = Δθᵢ · R · cosαᵢ / dᵢ²              （立体角/单位 z 长度）
τᵢ(x) = 分层直线走时（样本数，与现有 DAS 查询同模型；两态索引公式见 §2）
tᵢ(x) = 声学时间（§2 两态公式）
p(τ), p′(τ)：裁剪线及其时间导数（§3.5 导数方案），线性插值到 τᵢ（maskOob 同现状）
bᵢ(x) = 2·p(τᵢ) − 2·tᵢ(x)·p′(τᵢ)
acc(x) += Wᵢ(x)·bᵢ(x)，Wᵢ = apodᵢ·ΔΩᵢ         （apod 默认 none=1）
image(x) = acc(x)/max(accW(x), 1e-12)，accW += |Wᵢ|   （拟定归一化，待审，§4.2）
```

- 权重比：Wᵢ/DAS(生产默认 q=1, Δθ·cosα/d) = R/dᵢ（cosα 项相同）。
- minDist 保护：Wᵢ 分母用 dsafe=max(d,minDist)；d→0 时 W 有界而 b→0。
- **待审决策点**：立体角配对 vs 公平 legacy-weight 对照的优劣互现（§4），由规划主代理裁定；若裁定保留立体角配对，上述即最终形态；若要求改选，按 §4 数据修订。

### 1.4 为什么不采用严格 2D 反演（维持）

严格 2D 反演（FHR log 核）不是"逐线滤波 + 局部反投影"结构，与任务 §7.5 架构约束冲突。单环平面 UBP 定位为近似：**不宣称**严格二维 FBP、绝对初始声压标度（单环下 ΣΔΩ 随位置变化）、分层介质下的严格性；**可宣称**与 Xu–Wang 相同的信号组合与权重结构、合成模型上的量化行为。升级路径（FHR log 核）不在本任务内。

### 1.5 与 MATLAB 注释的核对结论（维持）

`bp = 2*p − 2*t*dp/dt`（das_recon_circular_gpu_v2.m 头注释）与 PRE 2005 的 b 项一致；注释未给出权重与归一化、未说明严格性边界。本阶段以其为出发点，依据以原文 + 数值验证为准。

## 2. 时间轴、索引与 delayCut 两态（exp3 已验证至两态完整反演）

### 2.1 索引链（与生产代码逐行对应）

- 原始行样本 m（1 基，1..sampDepth）。
- `preprocessBlock`（ring_recon.cpp:118–127）：delayCut=1 输出行数 = Nt−sysDelay+1，输出样本 k（1 基）= 原始样本 **k+sysDelay−1**；delayCut=0 时 k=k（srcRow0=0，全行保留）。
- CUDA/CPU 查询：tf=d·fs/c(+分层) 为连续采样数；1 基样本 k 位于连续坐标 **τ=k−1**；线性插值，maskOob 越界置零。**CUDA 查询无 systemDelay 引用**（ring_recon_cuda.cu 全文无该符号）。
- 裁剪线连续坐标 τ ⟷ 原始连续样本坐标 m(τ)=τ+sysDelay（delayCut=1）或 τ+1（delayCut=0）。

### 2.2 声学时间与两态查询公式（R3 冻结约定）

原始样本 m 的声学时间 **t(m) = (m − sysDelay)/fs**（sysDelay 经验校准"触发→声学零点"，每波长/通道独立：wl1=358、wl2=371）：

| 状态 | 查询坐标 | 声学时间 | 原始行取值位置 |
|---|---|---|---|
| delayCut=1（裁剪） | τ = d·fs/c(+分层) | **t = τ/fs** | 原始连续坐标 τ+sysDelay |
| delayCut=0（全行） | τ₀ = d·fs/c(+分层) | **t = (τ₀ + 1 − sysDelay)/fs** | 原始连续坐标 τ₀+1 = τ+sysDelay |

同一物理走时下两态取到**同一原始样本、同一插值分数**——exp3 T5 实测两态 p/p′/b 差 ≤ 9.8e-15 / 3.1e-11（浮点级），跨通道（358/371/359）差为 0；分层走时（T6）两态差为 0。不把 sysDelay 加回 t。

### 2.3 生产 delayCut=0 旧行为与拟议反演语义的区别（R3 必报项）

**生产 delayCut=0 不做等价延时校正**：kernel 查询 tf=d·fs/c 直接作用于存储的全行，隐含"原始样本 1 = 声学零点"；拟议语义要求 t=(τ+1−sysDelay)/fs。exp3 T5 实测：同一声学信号（sysDelay=358 写入）不补偿查询时 p 偏差达 **0.985**（≈信号错位 sysDelay/fs = 1.43µs ≈ 2.13mm 径向）。

定性：这是**旧路径兼容行为与拟议反演语义的差异，不是已查明的生产查询 bug**（生产 delayCut=0 在旧行为约定下自洽）。**阶段 B 局部适配要求**：反演（及滤波）模式启用时，要么 (a) 查询时间改用 tf_eff = tf + sysDelay − 1（原始行坐标），要么 (b) 强制 delayCut=1；两方案对用户可见行为的影响（delayCut=0 + 反演时的报错/自动切换）由阶段 B 决定并测试。本阶段未修改任何生产代码。

### 2.4 脉冲测试结果（exp3 T1–T4，维持）

- T1 索引链：峰位 τ=671.00 vs 期望 671.14（−0.14 样本，网格量化内）。
- T2 对齐：p 峰 −0.140 样本；p′ 过零 +0.010；b 主过零 **+0.003 样本**——p/p′/b 无 ±1 错位。
- T3 delayCut=0：raw 峰 m=1029 vs 期望 1029.14；t 公式自检误差 −0.56 ns。
- T4 ±1 样本敏感性：b 主峰偏移 +2.860/+0.860 样本（差恰 2.0）——可分辨一采样点错位。
- T5 补充：±1 样本扰动下固定走时处 |Δb| = 255.6（≥0.1·|b|max）——两态框架下同样可分辨。

## 3. 滤波顺序、端点与 DBR/边界策略（exp5 重写，R4）

### 3.1 拟定处理顺序（每根 A-line 独立，无跨线状态）

```
raw(m) → [DBR 置零 1..maskLength+dbrmaskExtra] → [削顶 ±imValue] → [DelayCut]
       → 高通零相位（整条裁剪线）→ 低通零相位（整条裁剪线）
       → [反演关] 直接进 DAS 查询   /   [反演开] 导数 p′ → b → UBP 查询
```

**归因分离证据（R5，exp5 B1，全部变体共用同一 refZeroPhase 实现）**：

| 比较 | echoOnly 远区最大相对差 | burstEcho 远区最大相对差 |
|---|---|---|
| 顺序效应：N（整线） vs M（历史切片 301:/sysDelay+20:），同实现 | 0 | 0.0133 |
| 实现效应：refZeroPhase vs filtfilt，同顺序 M | 1.61e-9 | 2.61e-9 |

- 顺序效应 0（无干扰）说明两顺序在稳态区等价；burst 下 1.3% 来自 M 的切片边界（301、378）切进 burst 暂态——这是顺序差异的真实来源，与实现无关（实现效应仅 e-9 量级）。旧版"提议顺序不劣于历史顺序（984.7 vs 1076）"的表述未分离实现因素，已由本表取代。
- burst 残留拖尾（>1%·burst峰）：N=1723 / M=1722 样本，等效；起点 50 样本（echoOnly）输出 |max| = 3.4e-18（≈0，稳态起点精确）。
- 不照搬 MATLAB 历史切片：切片起点落在查询区内且无稳态依据（维持）。

### 3.2 滤波器规格（维持）

double SOS（butter→zp2sos，Wn=2·fc/fs，fc 单程 −3dB）、奇对称延拓 nfact=3n + 逐节稳态初始化、前向+反向、复合增益 g²；高通 fc=0.4MHz/n=4 默认，低通 fc=40MHz/n=4 默认，首版阶数 1–8；fc 处单程 0.7071/双程 0.5000（exp6 F1 解析精确）；线长≤3n 报错、非有限输入报错；内部 double 输出 float；与经典 tf-filtfilt 交叉验证 n≤4 ≤7.4e-9，n≥5 tf 形式自身病态（维持原结论；本轮 exp6 未改码重跑复核通过）。

### 3.5 导数方案（R1 冻结约定）

### 4.3 结论修订（撤回 + 待审决策点）

- **撤回**：旧报告"错误配对位置误差 2.0–2.83mm、FWHM 4.0mm（配对 0.6–1.2/0.4–1.6mm）"——该数值是符号图的伪影（旧 discWrong cv=0、四目标 amp≡1）。公平对照下 legacyW 环内位置误差 0–0.2mm、FWHM 与 ubpD 相当。
- **撤回**：旧"accW 归一化最优（CV 0.0874 vs 原始和式 0.19）"中 das 0.0901 的对照基数——旧 das 权重标签错误（§0.4）。修正后：ubpD（0.0080）仍是盘内平坦度最优；ubpP（0.1084）仍是绝对标度最差（近场 15.9→修正后 1.137，环外放大仍存在但幅度不同）。
- **互现（不得只引其一）**：ubpD 盘内 CV 最优、近场伪影低于 legacyW（0.616 vs 1.087）；legacyW 点目标 CNR 更高（15.6 vs 9.2）、环外位置误差更小（0.283 vs 1.131mm）。**立体角配对（ubpD）仍是物理依据明确的拟定方案，但其相对 legacyW 的优势不再是全面性的**——是否维持"反演开启即切换立体角权重+accW"的拟定设计，作为决策点返回规划主代理；若裁定维持，阶段 B 按 §1.3 实现；若要求折中（如权重可配），需新增参数并走方案变更。
- 测试不预设优劣：exp2 断言门仅含正确性项（标定、legacyW 非符号图（cv≥0.01）、幅值保留（对比度≥3）、中心位置、有限性），无任何模式优劣断言。
