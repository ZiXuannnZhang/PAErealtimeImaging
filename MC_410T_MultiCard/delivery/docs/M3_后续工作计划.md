# M3 后续工作计划（8 通道扇区环形实时成像移植）

> 原补充说明已整合到[环形成像技术说明](../../../docs/环形成像技术说明.md)。本文保留阶段计划背景；当前版本与待办以[项目现状](../../../docs/项目现状.md)为准。
> 项目本质：把 ogprog 线性扫描实时成像实例移植为环形扫描实时成像；
> 除环形特有适配外，其余设定与线性实例一致。

## 0. 已确认的关键约定

| 项目 | 约定 |
|---|---|
| 触发粒度 | 1 触发 = 8 通道同步采集 = 8 根 A-line（每通道 1 根） |
| 波长交替 | 奇数触发 = 波长1（532nm），偶数触发 = 波长2（1064nm），全通道同步 |
| DAS 输入 | 与线性实例一致：DataProcessor 输出的频率数据（freqA/freqB, kHz）作为 A-line |
| 组包计数 | 按单通道 A-line 数计；每通道每块 200 根（面板“组包列数”，默认 200） |
| 采样参数 | 每根 A-line 采样点数/采样率由前面板输入，相关参数按输入换算 |
| 通道选择 | 前面板 8 通道勾选；未勾选通道不参与组包与重建 |
| 扇区分配 | 选中通道按序号从小到大，以逆时针方向从 9 点钟方向起均分 360° |
| 扇区推进 | 通道内同一波长 A-line 在扇区内随旋转均匀推进角度 |

## 1. 阶段 A：几何与数据模型

- 扩展 `RingReconCudaConfig`（及前端控件）：
  - `enabledChannels[8]`（勾选通道）
  - `alinesPerChannelPerBlock`（每通道每块 A-line 数，默认 200）
  - `alinesPerChannelPerFrame`（每通道每波长每圈 A-line 数，前端输入，用于扇区角度换算）
  - `sectorStartDeg`（首通道扇区起点，默认 180°=9 点钟）与旋转方向（默认逆时针）
  - `triggerWlOdd`（奇数触发=波长1，固定约定）
- 角度映射函数（CPU 侧统一计算）：
  - 选中 M 个通道 → 扇区宽 = 360°/M
  - 通道 c（按选中序号 i=0..M-1）扇区起点 = 180° + i×360°/M
  - 通道内第 k 根该波长 A-line 角度 = 扇区起点 + k/(K-1)×扇区宽（K=每通道每波长每圈 A-line 数）
- 环形块共享内存扩展：原始块（未切分/未对齐）之外，附加每根 A-line 的
  通道号数组与通道内全局序号数组（或直接附加每根 A-line 角度数组）。

## 2. 阶段 B：实时数据链路（UDP → 组包）

- `RingBlockAssembler`（跨线程，参照 FramePublisher 的跨卡组帧思路）：
  - 每个 DataProcessor（每卡）提交本卡 A/B 通道对应触发下的 A-line（频率数组）
  - 按 triggerSeq 对齐：同一触发下所有勾选通道到齐后，逐通道追加到块缓冲
  - 每通道计数达到“组包列数”（200）→ 组装一个完整块（含元数据）→ 队列/信号交 GUI 线程
- `DataProcessor` 环形模式：
  - 沿用现有 UDP 重组与 `computeFrequency`，环形模式额外把 freqA/freqB 交给 assembler
  - 未勾选通道直接跳过
- `ImagingController::submitRingBlock` 扩展为携带元数据（通道号/角度数组），
  ImagingSvc 环形模式按元数据进行波长切分、通道对齐与角度映射。

## 3. 阶段 C：重建核心适配

- CPU/CUDA DAS 从“整块均匀角度”改为“每根 A-line 独立角度”：
  - CUDA API 新增 `ring_recon_cuda_append_angles(handle, bscan, nt, nd, thetaDeg[])`
  - 原均匀角度接口保留（用于单探测器模拟/回归）
- ImagingSvc 环形预处理：
  - 按元数据按通道重组 → 按触发奇偶切分波长 → 每通道/每波长计算角度
  - ShiftWL2 对齐仍按“首块不偏移、后续块用上一块末列”的约定（在每通道内进行）
- 前端控制台：
  - 8 通道勾选、每通道每块 A-line 数、每圈每通道 A-line 数、采样点数/采样率、
    扇区起点等参数控件；实时显示各通道扇区分配示意

## 4. 阶段 D：联调与验证

- 用现有 11.dat/14.dat 构造 8 通道合成数据：
  - 把单探测器连续 A-line 按“每触发 8 根”轮转映射到 8 通道（A-line t×8+c → 通道 c 触发 t）
  - 验证：8 通道全选时重建图像与单探测器整圈重建结构一致（扇区拼接正确）
- 数值/性能验证沿用 compare 脚本；GUI 模拟采集 + 通道勾选验收
- 线性扫描分支保持原样，不做改动

## 5. 阶段 E：真实采集接入

- RingBlockAssembler 对接真实 UDP（按 triggerSeq 跨卡对齐、勾选通道过滤）
- 丢帧策略：不完整块丢弃（与线性实例一致），后续按需补零
- 性能基准：8 通道 × 200 A-line/块、CUDA 重建耗时与帧率达标确认

- RingBlockAssembler / DataProcessor 环形适配 / 每 A-line 角度 CUDA 核心
- 验证脚本与文档更新
