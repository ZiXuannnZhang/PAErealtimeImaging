# 测试结果摘要（2026-09-12）

## 新增确定性测试

### paimage_discovery_checks（状态机/传输替身，14 项）

PASS discovery policy: local exclusion, 60-byte-only admission, slow retries, ordering, cancel, stale sessions

覆盖：本机地址排除且零发送；ICMP 成功无 60 字节不确认；ICMP 超时 + 60 字节确认；第 3 轮才确认的慢响应接纳；重复 ACK 计数；18 字节不确认；59/61 字节忽略；非候选源忽略；先于发送的 ACK 忽略；sendto 持续失败 SendFailed 且不影响他人；全部超时返回空；乱序确认数值排序；等待中取消及时退出；旧 discoveryId 回调不覆盖新会话；绑定失败直接报错；参数规范化。

### paimage_discovery_socket_checks（本机 socket 集成）

PASS discovery socket: CONFIG on 8080, ACK on 8000, per-round resend, rebind, occupied failure

方式：Windows 回环 127.0.0.2–.5 绑定 8080 模拟四个不同源 IP 的候选卡。验证：CONFIG 只发 8080；60 字节反馈从 8000 接收且源 IP 映射正确；每轮只重发未确认候选（慢卡第 2 轮被重发并确认，verifiedRound=2、attemptsSent=2）；发现结束后 8000 可立即重新绑定；8000 被占用时明确失败（WinSock 10048）且不发送 CONFIG。

限制：Windows 回环无法模拟"down 接口本机地址 + 多源 IP"的真实组合，本机排除由状态机测试与实机日志验证；未为通过测试削弱生产过滤规则。
