### 2.2 接口

```cpp
namespace ringphantom {
struct Source   { double x, y; double amplitude; };            // 已知真值点吸收体
struct Geometry { double fs = 250e6; double c = 1490.0; int sampDepth = 4000; };
enum class PulseShape { Delta = 0, GaussDeriv = 1, Ricker = 2 };
struct ForwardParams {
    PulseShape pulse = PulseShape::GaussDeriv;
    double pulseWidthSec = 4.0e-9;
    double spreadExponent = 0.0;      // 0 = 不计几何扩散
    double referenceDistance = 1.0;
    bool   directivity = false;
    double startDelaySec = 0.0;
};
std::vector<float> simulate(sources, thetaRad, radii, geo, fp);  // 列主序 bscan[j*Nt + i]
std::vector<Source> uniformDisk(cx, cy, radius, amplitude, nPointsPerRadius);
double pulseValue(PulseShape, double u, double sigma);
}
```

输出布局 `bscan[j*Nt + i]` 与 `dasReconAppend` 的输入一致；`radii.size()` 必须等于
`thetaRad.size()`（不匹配返回空向量，不崩）。

### 2.3 波形选择是实质性的，请按用途选

| 波形 | 形状 | 用于 |
|---|---|---|
| `Delta` | 单极（高斯近似冲激，面积 1） | **定位/位置误差**断言（峰值位置明确） |
| `GaussDeriv`（默认） | **N 形**（奇函数，`g(0)=0`，正后随负） | **反演核差异**断言 |
| `Ricker` | 带限墨西哥帽 | 带限敏感性 |

**不要用 `GaussDeriv` 做峰值定位断言**：它是奇函数，峰值在旁瓣上，位置误差会是假的。
契约测试 P2/P3 正是因此改用 `Delta`。

## 4. 一个已量化现象（D7 不必重新发现，但要按模式重测）

`GaussDeriv` 是奇函数，在**完整 360° 环**上，36 根 A-line 的反对称响应在吸收体处
互相抵消：

| | 真值处相对幅度（vs 自身峰值） |
|---|---|
| 普通 DAS | **0.0654** |
| UBP 反演核（`b = 2p − 2t·p′`） | **1.0** |

这正是光声反演要解决的问题。**两点务必注意**：

1. **绝对量级不可比** —— UBP 峰值 ~2.76e11 vs DAS ~6.6e6，因 `b` 的量纲与权重族不同。
   只有**空间分布**与**真值处相对幅度**可比。
2. **该数字只对全 360° 环成立**。`spliceMode = 0/1` 各自的表现是 D6 的核心产出，
   本补充**不预先声称**，须由 D6 实测。
