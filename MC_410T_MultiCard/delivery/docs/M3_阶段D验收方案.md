# M3 阶段 D：环形扫描控制台验收方案

## 验收对象

`build\mingw_debug\bin\MC410T_Receiver.exe`（Debug 构建），入口为主窗口
“显示”分组中的“环形扫描控制台”按钮。

控制台基于模拟采集：从本地 .dat 文件按块读取 A-line，按勾选的通道数
构造 8 通道扇区块，经共享内存 + ZMQ 送入 `ImagingSvc.exe`（CUDA 环形
重建），实时显示 532nm / 1064nm 两幅重建帧。

## 验收步骤

1. 启动上位机，点击“环形扫描控制台”。
2. 数据集选 `14.dat`（360° 全圆覆盖，适合扇区验收），点击“选择数据文件”，
   选择 `D:\zzx\data\20260519\14.dat`。
3. 参数核对（默认值已按验收场景设置）：
   - 默认数据集为 14.dat（360° 全圆），8 通道全部勾选；
   - 每通道每块 A-line 数 = 200（符合实际采集约定，14.dat+8 通道共 5 块）；
   - 每通道每波长每圈 A-line 数 K = 500 由数据集与通道数自动换算；
   - 首通道扇区起点 = 180°（9 点钟方向），逆时针均分 360°；
4. 点击“启动环形重建”，观察两幅图像逐块更新、状态栏显示块进度。
5. 验收点：
   - 8 通道：重建帧有信号且覆盖全部 8 个扇区（全圆周），532/1064 均有内容；
   - 一致性：14.dat 下 8 通道重建应与 1 通道整圈重建完全一致
     （同一组 A-line 与角度，仅按扇区切分到各通道；wl1 相关系数 ≈ 1.0）；
   - 只勾选通道 1+2（其余取消）：重建仅来自两个对向 180° 扇区；
   - 修改参数（扇区起点、FOV、声速等）→“应用参数”→重新启动，图像随之变化；
   - 停止/再启动可重复执行。
6. 数据集 `11.dat`（180° 覆盖）仅支持单通道：切换数据集时其余通道自动取消，
   图像与 MATLAB 参考/M2 验收输出一致（wl1 相关系数 ≈ 1.0）。

## 已知说明

- 模拟采集把单探测器文件的 A-line 按角度扇区**连续切分**给各通道
  （通道 s 取文件内角度落在其扇区的连续 K 根 A-line），与真实采集中
  “每通道对应各自扇区传感器”语义一致。
- 多通道模拟要求 360° 数据集（14.dat）；11.dat 只有 180° 覆盖，自动切单通道。
- 真实采集接入（UDP 组包 → 按触发对齐 8 通道 → 每通道 200 A-line 组包）
  为阶段 B 工作，完成后替换模拟采集入口。
