# 环形成像技术说明

依据 `main@f326056` 源码整合原根目录重构设计、重构报告、多扫描半径方案、补充说明、显示点数评估及交接手册。本文描述已经存在的实现，不保留早期施工步骤和已废弃替代方案。

## 数据链路

`MultiPortReceiver → DataProcessor → RingBlockAssembler → ImagingController → SHM/ZMQ → ImagingSvc → CUDA snapshot → SHM → UI/PNG`。

网络接收、处理、存储与 UI 分线程运行。RingBlockAssembler 按触发与物理通道组织原始 A-line、角度和通道号；短 A-line 补零，pending 按首次进入顺序淘汰。服务端完成逐通道预处理、按波长展平和 CUDA 增量重建；显示使用快照，圈末或空闲超时触发相应保存/复位流程。

源码入口：[DataProcessor](../MC_410T_MultiCard/delivery/src/DataProcessor.cpp)、[RingBlockAssembler](../MC_410T_MultiCard/delivery/src/RingBlockAssembler.cpp)、[ImagingController](../MC_410T_MultiCard/delivery/src/ImagingController.cpp)、[ImagingSvc](../MC_410T_MultiCard/delivery/src/ImagingSvc/ImagingSvc.cpp)。

## 采样、角度与双波长

采样率由 Constants.h 的 `FPGA_ADC_FREQ_HZ=250e6` 和 `FPGA_ADC_INTERVAL_NS=4.0` 统一定义。采样点数由采集时间换算；旧注册表采样率只用于兼容告警/回写，不是另一份有效采样率。原补充说明中“采样率通过前面板输入”的说法已失效。

启用通道按物理通道序号分配扇区，通道顺序决定扇区位置；典型首通道起点为 180°，沿逆时针方向推进。双波长交替触发；每通道每波长每圈 A-line 数由单圈总量、启用通道数与两个波长换算。角度公式和首触发波长归属以 assembler 中的配置及计数实现为准，不把物理通道号等同于启用列表下标。

## 多半径与每通道延时

配准配置使用 `multiRadius` 与 `radiusPerChannel[8]`。UI 半径以 mm 输入，重建以 m 使用；未开启多半径时统一为通道 1 半径。ImagingSvc 根据 SHM 的 ch[]，按与信号/角度相同的顺序展开逐 A-line 半径，调用 ring_recon_cuda_append_angles_radii。波长 2 跨块对齐时，信号、角度和半径必须同步移动。拼接模式及羽化参数属于配准重建配置，羽化范围在服务端约束。

每通道双波长延时通过 `sysDelayPerChannel[8][2]` 传递，缺省时兼容旧 sysDelay[2] 广播。sysDelay 是从 1 开始的截断位置，波长 2 的额外 DBR 掩码差为该通道两波长延时之差。逐通道延时保存在主程序/服务端状态中，没有放入 CUDA 配置结构体。

RingReconCudaConfig 是 DLL ABI 的一部分。变更其布局时，DLL、导入库及所有消费端需要同步重建；不能混用不同布局的二进制。

## SHM 与显示

RingImagingShmHeader 为 64 字节，环形成像协议版本为 2；布局依次包含 Header、原始块、角度、按 4 字节对齐的物理通道数组和双波长帧。当前方案的显示帧与全分辨率帧共用区域。附接时需核对 magic、版本、尺寸及布局，偏移量直接使用 [ImagingSharedMemory.h](../MC_410T_MultiCard/delivery/include/ImagingSharedMemory.h) 的函数，不在调用侧另写常量。

block_ready/block_seq、通知/消费计数及 SHM 时延观测用于发现覆盖、重复、空 ready 和序号间断；观测本身不表示已消除生产丢包。

“显示最大点数”控制时域/频域显示快照，成像和文件保存使用全分辨率数据。当前源码仍保留该控件；旧报告中删除控件的设想不是已实施功能。提高显示点数会增加拷贝、FFT 和绘制负担，实际代价需按通道数和采集参数测量。

## 性能证据边界

[18 组基准原始数据](基准测试/重建核心基准测试_raw.csv) 是 2026-08-16、fd98556 的重建核心测量，保留为有明确版本的原始证据。条件为 i9-14900HX、RTX 4060 Laptop 8GB、250MHz、50μs、4000×4000 网格，合成数据，1/2/8 通道与 10/50/100 A-line 块，配准/拼接两模式。

测量包含预处理、CUDA append 和 snapshot，不包含完整网络、SHM、UI 和保存开销；不能据此宣称当前主线或实机达到某个帧率。旧报告中的当前性能推荐、旧构建路径和旧机器环境结论不再保留。
