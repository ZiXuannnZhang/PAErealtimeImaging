# 移植差异与限制

候选版production-3。核心源码按PAimage机器码恢复，名称为PAimage-derived。不是原EXE复用，不是完整原源码，不声称原EXE动态对拍。

## 必需宿主适配

| 适配 | 原因与影响 | 验证 |
|---|---|---|
| Qt计时器管理CONFIG确认 | 保持UI响应；源4轮/每轮发送后1秒、只发未ACK目标不变；管理超时增加最多约一个20ms tick | 控制组件及生产ACK→START |
| 空本地IP只读查询Windows路由再明确绑定 | 源要求具体IPv4，兼容宿主原配置；不修改网卡/ARP/防火墙 | loopback绑定及报文 |
| 使用宿主目标IP列表 | 保留原扫描/配置流程；目标对应socket索引 | 4卡非默认loopback地址 |
| 在原始组包bytes接宿主 | 不迁移PAimage下游比例；整数仅一次转float；B/A、4ns、样本数及float16保存不变 | 5000/12500逐样本及保存黄金值 |
| 参数修改内部重建listener | 源listener配置不可变；每段新run；队列残留记录；保存文件翻滚续序，防止覆盖 | 20→50→20，保存文件000/001/002 |
| 设置socket缓冲/非阻塞失败拒启 | 源未检查这些返回值；恢复版不在未知配置下静默运行 | 显式错误分支；未注入所有OS设置失败 |
| 接收线程异常退出通知宿主并停止 | 源接收循环已退出，UI应能看到失败；不自动回退旧链路 | 静态路径检查；真实select硬错误未强行注入 |
| 源同步blockSize固定50 | 对齐任务指定实验；普通队列阈值100同步对象，满时删队首整块 | 队列组件验证；其它block取值不作对照验收 |
| 独立INI与日志目录 | 首次只读复制旧参数，之后只写本程序INI；保存路径仍由用户选择 | 代码审查；实际GUI持久化待解锁 |

## 旧文件改动必要性

NetworkController.h/.cpp：替换生产装配/控制/统计；不创建旧接收处理线程。DataProcessor.h/.cpp：提取已组包分发入口和直接保存sink，旧组包不参与新路径。DataTypes.h：旁路来源IP。FileSaver.h/.cpp：提取原单组保存体并保持格式，单源worker调用，增加参数重启翻滚；数值格式与命名模板未改。

DiagnosticRecorder.h/.cpp：固定切面捕获与ZIP扩展。MainWindow.cpp：实验标记菜单与独立INI。RingConfigDialog.cpp/ImagingDisplayWindow.cpp：仅参数存储路径隔离。main.cpp：独立身份、日志、异步hash、参数首次复制与导出注册。AcqConfig.h：默认启用诊断的测试对照开关。CMake及tests：新组件、独立EXE输出和实际生产回放。

重建服务/算法、CUDA、DAS、Ring数值逻辑、图像处理、波长尾列与UI整体布局没有修改。预编译CUDA依赖仅复制，cufft来源/hash见证据索引。

## 可观测性限制

Raw ingress仅指recvfrom返回，不能区分网卡/驱动/内核丢失。首到packet锚不一定是物理slot0；跳号仅为估计。18byte ready不等同60byte CONFIG ACK；协议无事务ID，不能排除旧ACK恰好迟到的物理情形。

源启动过滤、不完整补零、同步丢弃、保存关闭及输出失败分别记录。stage7表示宿主入口返回，不表示磁盘持久化或GPU重建完成。源部分计数混合卡/同步事件，不强行换算包数。

轨迹16MiB内存、64MiB分段、每run1GiB；用满后新记录丢失但精确计数，分析器按序号输出缺失范围及traceIncomplete。长期多run目录不会被旧500MiB日志清理器清理，需要实验后导出并人工管理空间。时间窗裁剪也标不完整，缺少窗口前对象锚时输出unknown。

已记录实际接收缓冲、线程优先级及CPU拓扑；驱动版本、线程亲和性完整查询目前标unknown。未自动调整网络或驱动。无硬件发送端真值，无外接网卡实测；不得宣称实机丢包改善。
