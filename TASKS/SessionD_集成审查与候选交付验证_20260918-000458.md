# Part I — Frozen A/B/C contracts to audit

## 5. Session A core round policy

最终源码必须继续满足：

### Startup filter

```text
X=0  -> 第一枚 new distinct = logical index 0
X=1  -> 第一枚 filtered，第二枚 logical index 0
X=N  -> 前 N 枚 distinct filtered，第 N+1 枚 logical index 0
```

- 多卡同一 `(measurementSession, triggerSeq)` 只消耗一个 physical/filter/logical slot；
- cache/late card 不增加 distinct/filter/logical counter；
- `roundComplete` one-shot；
- `isFinalLogicalTrigger` stable；
- bounded recent-decision cache；
- `RoundIdentity=(measurementSession, roundGeneration)`。

### Count policy

```text
disableCountBoundary=false
  -> configured count 是 CountBoundary

disableCountBoundary=true
  -> configured count 不产生 boundary/final/generation advance
```

physical idle timeout 与 SourceCore per-card packet assembly timeout 必须继续分离。

## 7. Session C variable-length production round

必须保持：

### disable=false

原 CountBoundary 行为兼容：

```text
logical 0..N-1 realtime/raw
N-1 final
CountBoundary exactly once
generation++
startup filter restart
```

### disable=true

configured count 仅为 realtime imaging cap：

```text
logical 0..N-1
  raw/save + sync/display/Ring/CUDA

logical >=N
  raw/save continues
  sync/display/Ring/CUDA suppressed
```

不 modulo，不在同一 physical round 重新开放 realtime cap。

### Active timeout

唯一 production idle-boundary owner：

```text
NetworkController 20ms poll
 -> Backend::poll
 -> HostOutput::pollPhysicalRoundTimeout
 -> PhysicalRoundNormalizer::timeoutBoundaryIfIdle
```

- check+transition 原子；
- 不依赖 imaging/recon-save/auto-save enabled；
- `AwaitingControl` partial-startup 也可 timeout；
- poll/classify race exactly once；
- cached late card 不刷新 timeout anchor；
- timeout 后 cap/new logical index 从 0 重开。

### Timeout closure

冻结顺序：

```text
1. TimeoutBoundary / new RoundIdentity
2. synchronous AutoSave new-round binding commit
3. capture immutable old-round reconstruction presentation
4. discard old Ring residual / clear ImagingBypass
5. send Ring/CUDA reset
6. stale cutoff or fail-closed snapshot admission
7. async old-round PNG disk write
8. next RoundIdentity clean start
```

- AutoSave screenshot 使用 `oldDirectory/recon_png`；
- manual mode 使用现有 manual recon dir；
- old queued raw writes 保持 old sessionGen；
- 不同步 drain FileSaver；
- lookup/reset failure fail closed；
- timeout residual 不生成 synthetic partial Ring block。

### No synthetic completion

不得出现 Session C 后新增：

```text
forced reconstructionComplete
synthetic sourceRoundComplete
expectedBlocks rewrite
synthetic final trigger
partial Ring block submit
dynamic CUDA geometry
angle modulo
raw stop at configured count
```

## 35. Delivery candidate readiness

只有以下全部满足才允许：

```text
SESSION_D_DELIVERY_CANDIDATE = READY
```

- standard full build PASS；
- full `bin/` staged；
- build-manifest 完整；
- git-receipt 完整；
- dependency-sha256 完整；
- file-sha256 完整；
- validation.txt 完整；
- critical runtime 来源可追溯；
- exact candidate SHA 已记录。

如果软件 PASS 但关键 runtime/hash/provenance 缺失，必须分别写：

```text
SESSION_D_INTEGRATION_REVIEW = PASS
SESSION_D_DELIVERY_CANDIDATE = BLOCKED
```

不得混为一个 PASS。
