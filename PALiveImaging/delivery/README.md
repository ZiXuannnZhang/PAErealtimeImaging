# PALiveImaging 全真采集交付包

环形扫描光声实时成像上位机（全真采集版）。本包不含模拟调试功能
（无文件模拟采集、无测试数据模式、无 UDP 回放工具），数据只能来自
真实采集链路：采集卡组 UDP → 监听程序 → 环形重建 → 双波长实时显示。

## 目录结构

```
PALiveImaging/
  delivery/
    bin/                 运行目录（可执行 + 全部依赖，开箱即用）
      MC410T_Receiver.exe   上位机监听程序（主程序）
      ImagingSvc.exe        环形重建子进程（CUDA）
    include/ src/ ui/ ...  生产源码（不含模拟调试代码）
    docs/                  技术文档
    handoff/               项目交接文档（MATLAB 参考 + 接力导读）
    build_mingw_debug.cmd  源码构建脚本
    README.md
```

后续优化接力请先阅读 `handoff/README.md`（架构、约定、待办），
算法细节见 `handoff/HANDOFF.md` 与各 MATLAB 参考脚本。

## 运行

直接运行 `bin\MC410T_Receiver.exe` 即可，无需安装。

## 真机采集流程

1. 采集卡组（4 卡 × 2 通道，共 8 通道）通过交换机与监听电脑相连；
2. 启动上位机，点击“开始监听”（自动网段扫描识别采集卡）；
3. 点击“环形扫描控制台”：勾选参与重建的通道、设置组包参数
   （每通道每块 A-line 数，通常 200）、采样深度、每波长每圈 A-line 数 K、
   扇区起点等，点击“启动环形重建”；
4. 在上位机下发采集配置并开始测量；
5. 控制台实时显示 532nm / 1064nm 重建图像。

## 固定目标 IP（可选）

真机使用固定 IP 或同机 UDP 联调时，可用命令行指定目标卡地址，
跳过网段扫描：

```
MC410T_Receiver.exe --target-ips 192.168.0.2,192.168.0.3,192.168.0.4,192.168.0.5
```

同机联调（配合包外模拟发送器）：

```
MC410T_Receiver.exe --target-ips 127.0.0.1
```

## 数据与协议要点

- 每张卡一个 UDP 端口：8001 + 卡号（8001~8004）；
- 包格式：4 字节头（packetSeq、triggerSeq，小端）+ 载荷；
- 载荷为 B/A 交织采样对（int16 或 int32 差分相位，由采集卡 FPGA 解调），
  监听程序换算为频率数据后送入重建；
- 一次触发 = 8 通道同步采集；通道勾选决定参与重建的扇区数量，
  每个启用通道均分 360°/N 扇区，逆时针从首通道扇区起点分配；
- 组包按每通道 A-line 数计数（默认 200 根/块），双波长交替、未切分，
  切分与 1064 跨块对齐在重建子进程预处理中完成。

## 源码构建

依赖 Qt 6.8 MinGW、CMake/Ninja、CUDA 12.8（ring_recon_cuda 模块）。
构建前需先编译 `src/RingRecon/ring_recon_cuda`（CUDA DLL 与 MinGW 导入库），
放到 `build/ring_recon_cuda/` 下，然后运行：

```
build_mingw_debug.cmd
```

## 已知限制

- 分层声速尚未实现（控制台分层边界数需保持 0）；
- F64（每通道 8 光纤）模式暂按单光纤处理。
