## 7. Recommended Design

### 7.1 数值模块

在CPU成像预处理层实现双精度Butterworth SOS设计和前后向滤波。可提取独立小模块，避免把设计/状态/缓冲全部塞入ring_recon.cpp。逐配置设计并缓存系数，复用工作区，不逐A-line重新设计滤波器。

与阶段A refZeroPhase约定对齐：
- 运行时fs，Wn=2fc/fs；阶数为单程阶数，支持整数1–8，默认4。
- SOS DF2T或数值等价结构；稳态初始化；奇对称两端延拓，各3n样本；前向、反转、前向、反转，正确应用两程增益。
- 高通先于低通；两者均可独立关闭。
- 滤波内部double，完成后转现有float输出；全关时保持旧路径转换顺序，不引入额外舍入。
- 使用现有处理顺序：DBR置零 → 削顶 → delayCut（若开） → HP → LP。滤波作用于当前完整输出线，不搬入MATLAB的301:/system_delay+20:硬编码切片。
- 系数、输入及计算结果不得有NaN/Inf；有效线长必须大于每个启用滤波器的3n。非法配置在启动/应用前拒绝，运行时遇到异常明确报错，不静默跳过滤波、改成单向或伪装成原DAS输出。
- 极端合法频率造成系数或初态数值不可用时，应返回可理解的设计失败，不产生无效图像；实现报告列明数值支持边界。

优先复用已有reserved字段表达相同含义，内部统一明确命名highpass/lowpass并集中映射。不要仅为方便改CUDA C ABI；需要额外服务状态优先放非CUDA配置。不得借用不相关字段。

### 7.2 配置有效性及DBR规则

前端与服务端均校验：有限参数；0<fc<fs/2；两个滤波同时开时hpHz<lpHz；启用滤波阶数1–8。关闭滤波保留输入值，但不以其无效截止值阻塞两者全关的旧运行路径；再次启用必须校验。使用实际daqHz与实际线长，不能固定250MHz。

按每个启用通道/波长计算D=systemDelay，E=实际DBR置零样本数（DBR关为0；开但有效长度0也为0；计入extra及行尾限制）。与现有预处理实际行为核对，不把DBR开关直接当作E>0。非法基础参数仍应明确拒绝；不要无记录改变现有extra语义。

```
HP/LP均关：不引入新的滤波专属拒绝。
任一滤波开，E=0：允许通过DBR相关校验。
任一滤波开，E>0，delayCut=true：只在E<D时允许。
任一滤波开，E>0，delayCut=false：本版明确拒绝。
```

所有启用通道/波长均通过才应用；报告具体失败通道/波长。提示为本版未支持该组合，并说明用户可主动调整裁剪/DBR，不自动切换。配置允许不保证端点无失真，保留文档限制。

### 7.3 服务接入与错误传播

检查并贯通 RingConfigDialog → ImagingController → 配置JSON → ImagingSvc → 逐A-line预处理。service端不信任UI值，重复校验。配置应用应避免一部分字段生效、一部分失败；尽可能先构建完整滤波配置后再替换。

不得在滤波失败时继续发布看似正常的图像；沿用合适的服务错误路径，让控制器/UI看见具体原因。不得导致原始采集/保存被无关的成像错误破坏。控制器忙闲判断使用现有真实状态，不只禁用一个按钮而留旁路。

不改变SHM输入/输出格式。核实wl2尾线究竟在滤波前还是后缓存，新增针对同一物理A-line只处理一次的回归；不要凭注释假定其正确。

### 7.4 UI与“设为默认”

复用主窗口现有成像参数入口和RingConfigDialog。预处理区域新增：

| 控件 | 默认 | 参数 |
|---|---|---|
| 高通零相位滤波 | 关闭 | 截止0.4MHz，单程4阶 |
| 低通零相位滤波 | 关闭 | 截止40MHz，单程4阶 |

两个开关独立；关闭时禁用该行数值输入并保留值。MHz显示、Hz传递，转换只做一次。说明“截止频率为单程−3dB点，双程在该频率约−6dB”，展示当前采样率及有效范围。

新增键接入既有RingConfigDialog/Defaults读取、保存与设为默认；旧配置缺键默认为关闭。恢复值与采样率不匹配时不静默改值，启用/应用前提示。取消对话框不应改变活动配置；设为默认与应用语义保持清晰。

不改距离指数控件；不出现尚未实现的反演开关或灰色占位功能。保留MinDistance和Apodization原交互。
