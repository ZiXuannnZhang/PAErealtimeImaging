# D7 重跑（环外真实工作区）与权重符号发现

- 分支：`codex/das-dual-wavelength-quality-b-tier-20260925`
- 日期：2026-09-25
- 性质：**只测不改生产代码**。D7 原版体模放错工作区，本目录是按内窥成像口径的重跑。

## 0. 口径修正（用户提供）

1. 本项目是**内窥成像**，实际声源都在探测环**外**；
2. 环内出现的是**对侧信号穿过整个环到达探头**造成的反投影伪影，不是源；
3. 处置：**不截断累加**，只在**显示层**加零值掩膜（半径 = 可调 R），不改重建。

⇒ D7 原版把点目标放在 `(3,1)` / `(−5,4)`（**环内**）是放错了工作区，其「UBP 环内目标失手」
结论不适用于本项目，须以本目录重跑为准。

## 1. 发现一：现有 DAS 权重的符号约定与内窥几何相反（**最根本**）

闭式核对（`scripts/signcheck.cpp`，输出 `out_weight_sign.txt`）：对**任意环外像素**，

| 该像素对应的探测器 | cosα | 权重 `w = Δθ·cosα/d` |
|---|---|---|
| **同侧（最近、直达信号最强）** | **−1.0000** | **负** |
| 对侧（最远、即穿行射线） | **+1.0000** | 正 |
| ±90° | +0.36 ~ +0.59 | 正 |

即：**最近、最有信息量的探测器拿最大负权重；穿过整个环的那条射线拿最大正权重。**
这个约定是为「源在环内」的标准 PAT 设计的，对「源在环外」的内窥几何**方向相反**。

图像侧直接印证（`out_d7b.txt` 符号统计）：所有用例的**负能量占比 49.6% ~ 51.0%**
—— 图像近一半能量是负的；Delta+DAS 的全局峰值本身是**负值**（−3.15e6）且落在 FOV 角落
（ρ=21.9 mm），不落在任何真目标上。

## 2. 发现二：环内伪影与目标同量级，显示掩膜确实需要

体模（全部环外）：A(ρ=9)、B(ρ=13)、C(ρ=17) mm；R=6.57 mm；gridSize=0.1 mm；360 A-line。

| 脉冲 | 反演 | 环内伪影 / 目标峰值 | 目标位置误差 (mm) |
|---|---|---|---|
| Delta | DAS | **0.92** | 1.86 / 1.24 / 1.00 |
| Delta | UBP | 0.24 | 1.11 / 1.66 / 0.96 |
| GaussDeriv | DAS | **1.00** | 1.71 / 1.66 / 0.96 |
| GaussDeriv | UBP | 0.21 | 0.80 / 1.57 / 1.00 |

- **DAS 的环内伪影与目标同量级（0.92–1.00）**，N 形脉冲下**全局峰值就是那个环内伪影**
  （ρ=4.24 mm）——与用户描述的「对侧穿行射线」现象吻合。
- **UBP 反而把环内伪影压到 0.21–0.24（约 4× 抑制）**，但代价是背景 std 高 3–4 个数量级。

## 3. 发现三：显示掩膜基本不改质量指标（这正合其定位）

掩膜前后 CR / gCNR / CNR **几乎不变**（唯一变化是 GaussDeriv+DAS 的 CR 54.19→53.13 dB）。
原因：目标 ROI 与背景 ROI 都在 `ρ > R`，掩膜只清环内，本就不在度量区里。

⇒ **显示掩膜的价值是视觉上的**（去掉与目标同强度的环内伪影），不是指标上的。
这与「只进行显示遮盖、不影响重建」的定位一致。

## 4. 与旧 D7 的对比（说明工作区选择的影响）

| | 旧 D7（目标环内） | 本重跑（目标环外） |
|---|---|---|
| DAS 位置误差 | **0.06 mm** | 1.00–1.86 mm |
| 环内伪影 | 未测 | 0.92–1.00 × 目标峰值 |
| 图像负能量占比 | 未测 | ~50% |

目标放到真实工作区后，位置误差恶化一个数量级——旧 D7 的「DAS 很准」是工作区放对了才成立。

## 5. 限制（如实）

- `gridSize = 0.1 mm`（项目默认 0.01 mm，计算量取舍）；
- A-line 360 根（真实系统 8000 根/圈），角步长 1°；
- 单声速、无噪声、无折射/透射、无有限探头尺寸（共享前向的既有限制）；
- 两种成像模式（全局/拼接）结果几乎相同 —— 因为本用例 360 根 A-line 均布，
  扇区门控对结果无实质影响，**不代表真实 8 通道扇区情形**；
- **未在实测数据上验证权重符号问题**（实测侧证据见 `out_fov_probe_realdata.txt` 的
  径向能量剖分：环外 87% 能量、环内峰值跨模式稳定、环外峰值跨模式漂移）。
