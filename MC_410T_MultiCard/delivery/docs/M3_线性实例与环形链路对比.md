# M3：线性实例数据链路逆向与环形链路对比

## 1. 线性实例（ogprog）从采集到实时成像的完整链路

```
采集卡组(4卡×2通道, 8通道同步, 1触发=8 A-line)
  → UDP: 每卡一个端口, 4字节头(packetSeq/triggerSeq, 小端) + 载荷
  → MultiPortReceiver: 按卡收包, 交对应 DataProcessor
  → DataProcessor: 按 triggerSeq 组包(bitmask去重/乱序容错), 完成一个触发即
    exportTo(TriggerGroup) → computeFrequency(int16 Q0.15/Q16.16 差分相位 → kHz)
  → 三路分发:
       FileSaver  : 每卡每通道写独立 .dat, float16 频率数据
       DisplayBuffer : 降采样显示 + updateFullRes(全分辨率 freqA/freqB)
  → 成像: MainWindow 每触发聚合 4卡8通道频率 → feedPulseData(cardId, freqA, freqB)
    → flushPulseData → 共享内存 [8通道×depth float] → ImagingSvc
  → pa_recon_core: pa_recon_single_pulse(8通道×depth 一维数组) → 线性 DAS → 帧
```

要点：
- 重建核心的输入是**每触发 8 通道 × depth 的一维频率信号**（freqA/freqB，kHz），
  不是原始电压，也不是分通道独立重建。
- 通道布局固定：`[卡0A, 卡0B, 卡1A, 卡1B, 卡2A, 卡2B, 卡3A, 卡3B] × depth`。
- 预处理与几何（声速、网格、延迟、滤波）全部在 pa_recon_core 内完成。

## 2. 当前环形链路

```
模拟采集(阶段D): .dat 文件(双波长交替列, double) 
  → 按角度扇区连续切分: 通道 s 取文件内角度落在其扇区的连续 K 根 A-line
  → 每块构造 trigger-major raw [M通道 × perCh × sampDepth] + 每根角度 + 通道号
  → 共享内存(环形布局: raw + angles + channels + wl1帧 + wl2帧) → ImagingSvc
  → ImagingSvc:
       按通道/触发奇偶分波长(wl1/wl2)
       → 每列 preprocessBlock(DBR掩膜+延时截断, 与 MATLAB preprocessBlock.m 一致)
       → wl2 跨块对齐(前插上一块末根)
       → CUDA ring_recon_cuda_append_angles: 每根 A-line 独立角度 DAS 累加
       → acc/accW 归一化 → 双波长帧写回 → 前端显示
```

要点：
- 重建核心输入同样是**每根 A-line 一维时域信号**（预处理后），与线性实例一致；
- 环形几何为探测器圆环 + 每根 A-line 独立角度（DAS/相干合成所必需）；
- 8 通道扇区模型：启用 N 通道 → 每通道 360/N 扇区，按通道序号从小到大、
  逆时针均分，首通道默认 9 点钟（180°）起。

## 3. 对比结论

| 环节 | 线性实例 | 环形实现 | 一致性 |
| --- | --- | --- | --- |
| 采集 | UDP 每卡一端口，按触发组包 | 阶段B：UDP 每通道一端口/文件，按触发对齐 | 待阶段B接入 |
| 输入重建核心 | 8通道×depth 频率(kHz)一维数组 | 每根预处理后 A-line 一维数组 | 一致（均为时域信号） |
| 双波长切分 | 外部不做，FPGA/数据流自带 | 组包按触发奇偶在 ImagingSvc 内切分 | 一致（预处理处切分） |
| 预处理 | pa_recon_core 内 | preprocessBlock（DBR/延时截断） | 与 MATLAB 参考一致 |
| 几何 | 线性平面网格 | 圆环扇区逐角度 DAS | 按环形模型 |
| 显示 | 单帧图 | 双波长双帧图 | 环形特有 |

## 4. 本次定位并修复的问题

1. **A-line→通道分配错误（图像完全错误的主因）**：原模拟把单探测器文件按
   `A-line i → 通道 i%8` 轮询分派，把同一扇区内的连续数据打散到不同角度；
   改为按角度扇区连续切分后，14.dat 下 8 通道重建与 1 通道整圈重建
   wl1 相关系数 = 1.0，wl2 ≈ 0.999。
2. **角度生成漏块偏移**：旧代码每块角度都从块首重新计，导致各块重叠在同一
   角度区间；已改为按全局 A-line 序号计算角度。
3. **11.dat 多通道不可用**：11.dat 仅 180° 覆盖，与 360°/N 扇区模型冲突；
   GUI 切到 11.dat 时自动单通道，多通道仅允许 360° 数据集（14.dat）。
