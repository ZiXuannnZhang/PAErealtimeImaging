## 4. Problem / Evidence

规划侧已用 MATLAB R2023a 在隔离副本复跑 exp1..exp6，总进程退出码 0；该结果只证明脚本可运行，不证明关键公式和比较正确。确认以下问题。

### R1 / P1：exp2 时间导数维度错误

`matlab/exp2_ring_ubp_2d.m:42,71`：

```matlab
ppdA = gradient(double(pAd), dr / c, 1);
```

矩阵为时间样本×A-line。MATLAB gradient 的单输出是沿列方向梯度；第三参数为间隔，不是 axis=1。均匀盘各列相同，所得“时间导数”为零；偏心目标得到跨 A-line 差分，错误参与 b 项。

独立最小复现：

```matlab
A = repmat((0:4)',1,3);
G = gradient(A,0.1,1);           % 返回全零，正确时间导数应为10
[~,Gt] = gradient(A,1,0.1);      % 第二输出才沿行样本方向，返回10
```

影响：exp2 图像和质量指标、权重/归一化建议、文档相关结论失去有效依据。

### R2 / P1：旧权重对照被自归一化成符号图

`exp2_ring_ubp_2d.m:46,74,210–233`：reconUBPwrong 仅返回 acc，单参数 normAcc 执行 `acc./max(abs(acc),1e-12)`。非零像素接近 ±1，不是旧 DAS 的 acc/sum(abs(w))。报告的误差和 FWHM 不能归因于权重。复跑时四个该对照目标峰值均为1。

### R3 / P1：delayCut=0 的完整反演证据缺失

exp3 T3 主要验证 raw p 峰位与时间换算；b 项对齐测试在裁剪状态进行。报告 §1.3 与 §2.2 分散给出两态说明，未形成同一物理查询的完整可执行约定。

此项是规格和证据缺口，不是已证实的生产查询代码 bug。不得误写为已查明生产实现错位。

## 7. Recommended Design / 必须完成的整改

### 7.1 正确导数与自动测试

明确时间轴，采用每列独立向量差分或正确矩阵维度方式；端点/中心格式和单位写清。检查所有脚本和导出向量中的 gradient，区分向量用法与矩阵误用，不做盲目批量替换。

添加可自动失败的断言：

1. 时间方向线性变化、各列相同，导数是已知常数。
2. 时间恒定、仅列间变化，时间导数应为零。
3. 多列不同振幅/频率解析信号，与解析导数比较，明确离散误差容差。
4. 向量与矩阵路径一致，端点单侧差分符合约定。

### 7.2 公平的权重/归一化对照

旧权重对照同时返回 acc 和 accW，使用同一 abs(w) 累积规则。将 normAcc 改为不允许缺失权重的显式接口，或隔离命名清楚的不同归一化函数，避免静默退化为符号图。

把“wrong”改为中性的 legacy-weight 等命名；对照应固定输入 b、几何、插值、有效掩码、角度采样、幅度标定与测量方法，仅改变要比较的因素。原始和式与 accW 比较另列，不混淆权重效应。

增加对照输出不退化为 sign(acc) 的测试，并验证正常幅度/形状信息被保留。重跑均匀盘、中心/偏心目标；环内与环外指标分开。若继续称FWHM为径向/切向，需沿目标相对圆心的实际方向采样；固定x/y剖面应按实际方向命名。无半高交点、峰在搜索窗边界或指标截断时标记不可用，不能把窗宽当作有效FWHM。

重新生成 JSON/MAT 和文档表格，重新评估公式/权重/归一化，不继承旧报告的优劣结论。

### 7.3 delayCut 两态完整反演与查询测试

在同一节/表格给出：原始索引、裁剪索引、校准声学时间、像素物理走时、实际取样索引及 b 计算。区分物理走时与数组索引；对于未裁剪线，应显式证明在同一物理到达时刻取到同一信号，而不只是给样本重新标时间。

构造相同声学 p(t) 加系统延时后的 raw 数据，分别走两态，在相同像素走时比较 p、p′、b。覆盖至少 sysDelay=358和371及通道差异、整数/亚样本走时、±1样本扰动、均匀声速及双声速路径时间。

若检查发现现有 DAS 的 delayCut=0 本来不做等价延时校正，必须明确区分旧路径兼容行为与拟议反演语义，报告必要的后续局部适配；不得暗中修改生产代码来让参考通过。

### 7.4 冻结有效区间与端点方案

用同一SOS实现比较合理的处理顺序和保护策略，覆盖：DBR末端早于/等于/晚于裁剪起点、双波长extra、启动强信号、靠近有效区间边界的真实目标回波、长/短窗口、高低通独立/组合及反演开关。

分别测启动干扰残留和有效目标误差，不能仅以两个很大的瞬态中较小者证明可接受。加入无干扰参考，量化幅值、位置及反演误差；阈值、依据及适用范围写明。

阶段A须选择一个确定、可实现且可测的默认策略，包括边界延拓、DBR排除、是否保留/替换不可信前段、有效查询区、端点导数及不满足条件时的错误行为。若必须新增参数或大范围屏蔽，则作为明确方案变更请求，不自行加到UI。不能以“阶段B再决定”通过本关口。
