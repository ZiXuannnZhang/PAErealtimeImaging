## 0. 结论摘要（审查要点）

1. **反演公式冻结为 Xu & Wang PRE 71, 016706 (2005) Eq.(20)–(22)**：信号组合 `b = 2p − 2t̃·∂p/∂t̃`（t̃ 用长度单位；等价于任务注释的 `2[p(t)−t·dp/dt]`，t 用秒），立体角权重 `dΩ₀ = dS₀·(n̂₀·(r−r₀))/r̃³`，输出 `(1/Ω₀)∮b·dΩ₀`。该式的精确性只对**完整 3D 闭合曲面 + 面内源**成立，已用紧支撑均匀球体验证（内部重构误差 6.4e-8，exp1）。
2. **与 MATLAB 注释的关系**：`das_recon_circular_gpu_v2.m` 文档注释 `bp = 2*p − 2*t*dp/dt` 与 PRE 2005 的组合**一致**；但注释未说明该组合的严格性边界。**本任务的环形几何不是完整 3D 孔径**（单环、无 z 向数据），**严格 2D 反演是非局部 log 核**（Finch–Haltmeier–Rakesh），不存在局部 UBP。生产采用"单环平面 UBP"（3D 公式逐平面应用）作为**近似**，不宣称严格二维 FBP——这是任务文档预警的"假设与几何实质冲突"点，证据与修订建议见 §3.3/§3.4。
3. **反演必须同时换权重**：立体角权重 `ΔΩᵢ = Δθᵢ·R·cosαᵢ/dᵢ²` **不是**旧 DAS q=1 权重 `Δθ·cosα/d` 的常数倍（多一个 1/d）。错误配对（只换信号不换权重）在 exp2 中位置误差 2.0–2.8 mm、FWHM 恶化 ~3×——证实任务约束"不能仅改变输入却沿用未经验证的经验权重"。
4. **配对归一化推荐 accW**（`acc/max(accW,1e-12)`，与生产 snapshot 现有路径一致）：exp2 均匀盘内平坦度 CV=0.087（DAS 0.090）优于原始和式归一化的 0.19，且输出有界、绝对标度在单环几何下本来就不守恒。原始和式（物理标度）作为备选记录，需改 snapshot 分支，不推荐 v1。
5. **时间轴冻结**（exp3 验证到亚样本）：裁剪线连续坐标 τ 的声学时间 `t = τ/fs`（delayCut=1）；`t = (τ+1−sysDelay)/fs`（delayCut=0）。不把 sysDelay 加回 t（每波长裁剪后已对齐各自声学零点）。p、p′、b 三者对齐无 ±1 样本错位；±1 样本错位在脉冲测试中产生 2.0 样本的 b 峰偏移，可被明确分辨。
6. **滤波顺序冻结**：DBR 置零 → 削顶 → DelayCut → 高通（整条裁剪线）→ 低通（整条裁剪线）→（导数/反演）。不照搬 MATLAB 的 301:/sysDelay+20: 切片（切片边界落在查询区内且无稳态依据）。exp5：提议顺序的起点瞬态 984.7 优于历史顺序 1076，burst 拖尾两者一致（~1745 样本）。
7. **滤波器规格**：double SOS、奇对称延拓 `nfact=3n` + 逐节稳态初始化、前向+反向；fc 为单程 −3dB 点（双程 −6dB，解析验证精确 0.7071/0.5）；线长 ≤3n 报错；参考实现与经典 tf 形式 filtfilt 交叉验证一致（n≤4 时 ≤7.4e-9；n≥5 tf 形式自身病态，见 §5.6——这是 C++ 用 double SOS 的依据）。
8. **滤波器记忆长度（新量化）**：0.4MHz 高通零相位冲击响应展宽 848–3639 样本（n=1..8，exp6 F5）。线起点该范围内输出依赖边界约定——阶段 B 的反演模式应将"DBR 阶跃 + 记忆长度"纳入有效区间定义（§5.5）。
9. **分层声速**：沿用生产直线分区走时（判别式实现与独立垂距弦长法一致到 3.2e-17 m；同声速退化 4.5e-13 样本；模型自洽位置误差 0.000mm，exp4）。分层下反演与 DAS 同为近似；不宣称非均匀介质解析反演。
10. **未验证/限制**（§9）：全部基于闭式合成模型，无真实采集数据、无噪声、无实机；合成体模上反演相对 DAS 的质量收益不确立（互有胜负）——质量结论留待阶段 C 的同数据对比；环外像素（FOV 半径 18mm > R=6.57mm）的 UBP 权重行为需阶段 B 决策（§6.4）。

## 1. 反演算法依据

### 1.1 文献锚点

- **主锚点**：M. Xu, L. V. Wang, "Universal back-projection algorithm for photoacoustic computed tomography," *Phys. Rev. E* **71**, 016706 (2005)（有 Erratum；本阶段公式取自原文正文 Eq.(19)–(22)，并经数值独立验证，不依赖 Erratum 修订项）。原文关键式（已取原文核对）：
  - Eq.(19)：`p0(b)(r) = −(2/Ω₀)·∇_r·∫_{S₀} n̂₀ dS₀ [p(r₀,t)/t]_{t=|r−r₀|}`（与 Finch–Patch–Rakesh 型精确式一致）；
  - Eq.(20)：反投影形式 `p0(b)(r) = ∫_{S₀} b(r₀, r̃=|r−r₀|)·dΩ₀ / Ω₀`，**`b(r₀,r̃) = 2p(r₀,r̃) − 2r̃·∂p(r₀,r̃)/∂r̃`**；
  - Eq.(22)：`dΩ₀ = dS₀·(n̂₀ᵢ·(r−rᵢ))/|r−rᵢ|³`，n̂₀ᵢ 指向源侧；Ω₀=4π（闭合面内点），平面 2π。
  - 原文实现节：b 项中时间一阶导数即频域 ramp 滤波；`k|r−r₀|≫1` 时 `r̃·p′ ≫ p`（导数项主导，见 §6.6）。
- 3D 精确式族：Finch, Patch, Rakesh, *SIAM J. Math. Anal.* 35, 1213 (2004)；Kunyansky, *Inverse Problems* 23, 373 (2007)。
- **2D（偶数维）精确式**：Finch, Haltmeier, Rakesh, *SIAM J. Imaging Sci.*？(2007)——log 核非局部式（转引自 Kuchment & Kunyansky 综述 Eq.(16)–(17)）：`f(x) = (1/2πR)·Δ_x∫_∂B∫₀^{2R} g(y,t)·log(t²−|x−y|²) dt dl(y)`。
- 综述：P. Kuchment, L. Kunyansky, "Mathematics of thermoacoustic tomography," *Eur. J. Appl. Math.* 19, 191 (2008)（arXiv:0704.0286）；其中明确：3D 常声速满足 Huygens 原理（信号有限时间离开），**2D 不满足**（Green 函数有尾部）——这是 2D 无局部 UBP 的物理根源。

### 1.2 精确性与验证边界（重要方法论结论）

Xu–Wang UBP 的精确性证明（原文 Sec. II，PSF=δ）要求：(a) 测量面为完整闭合曲面（球/柱/平面+无穷远补全）；(b) 源在面内（紧支撑）。因此：

- **本征模式（J 基/球 Bessel）不能用作验证数据**：模式延伸到面外，公式在面外源上不成立。阶段 A 初版判据实验（对 `f=J_m(kr)cos(mθ)` 检验候选权重）因此作废——它对任何候选权重都不满足恒等式，是测试对象选错，不是公式错误。该教训记入本文档以防复查时重蹈。
- **有效验证必须用紧支撑源 + 闭式前向**。exp1 用均匀球体（球-球相交立体角分数闭式 + 3D Poisson `p=∂_t[t·M]`）验证：`C=1/Ω₀, b=2p−2r̃p′, dΩ=dS₀(n̂₀·(r−r₀))/r̃³` 组合下球体内部重构 = f₀，最大误差 **6.4e-8**（求积精度）；半常数变体偏差 0.5，被否定。球外负值随求积分辨率收敛（−0.358→−0.098→−0.051），确认为验证脚本对切点 1/√ 奇异性的求积伪影，非公式问题。

### 1.3 生产冻结公式（阶段 B 按此实现）

对每个像素 x、每根 A-line i（探测器 x₀ᵢ = R·n̂₀ᵢ，外法向 −n̂₀ᵢ 指向源）：

```
dᵢ    = |x − x₀ᵢ|                          （直线距离，≥ minDist 保护见 §6.5）
cosαᵢ = (R − x·n̂₀ᵢ)/dᵢ                     （= −dotpᵢ/(R·dᵢ)，dotpᵢ 为生产核现有量）
ΔΩᵢ   = Δθᵢ · R · cosαᵢ / dᵢ²              （= Δθᵢ·(−dotpᵢ)/dᵢ³；立体角/单位 z 长度）
τᵢ(x) = 分层直线走时（样本数，与现有 DAS 查询完全同模型）
tᵢ(x) = τᵢ(x)/fs                            （delayCut=1；两态公式见 §4）
p(τ), p′(τ)：裁剪线及其时间导数（§5 导数方案），线性插值到 τᵢ（maskOob 同现状）
bᵢ(x) = 2·p(τᵢ) − 2·tᵢ(x)·p′(τᵢ)
acc(x) += Wᵢ(x)·bᵢ(x)，Wᵢ = apodᵢ·ΔΩᵢ        （apod 默认 none=1）
image(x) = acc(x)/max(accW(x), 1e-12)，accW += |Wᵢ|   （配对归一化，§6）
```

注意：

- `Δθᵢ` 为逐线角步（由 thetaDeg 相邻差均值；现有 wscale 用块内均值 Δθ̄，阶段 B 可沿用块内均值并记录差异）。
- `Wᵢ` 中 d 用 dsafe=max(d,minDist) 保护（分母），cosα 分子用真实几何量；d→0 时 W 有界（~Δθ·R·cosα/minDist²）而 b→0（该处信号为裁剪线起点，见 §5.5），乘积有界。
- **权重不是旧权重的常数倍**：Wᵢ/DAS(q=1) = R/dᵢ·(cosα 项相同)。任务约束"反演开关同时选择配套几何权重与归一化"的数学内容即此。
- 卷积性缩写：反演模式 = "把每线查询信号从 p 换成 b、权重从 Δθ·cosα/d 换成 Δθ·R·cosα/d²、归一化保持 accW"。

### 1.4 为什么不采用严格 2D 反演（修订建议记录）

严格 2D 反演（FHR log 核）要求：每线先做非局部时间积分（log(t²−τ²) 核，积分限 0..2R/c），再对图像做 Laplacian——**不是**"逐线滤波 + 局部反投影"结构，不能在现有 CUDA DAS 核内以"权重/归一化局部适配"实现，与任务 §7.5 的架构约束冲突。故本任务采用单环平面 UBP 近似，并明确：

- **不宣称**：严格二维 FBP、绝对初始声压标度（单环下 ΣΔΩ 随位置变化，绝对标度不守恒，exp2）、分层介质下的严格性。
- **可宣称**：与 Xu–Wang 3D UBP 相同的信号组合与立体角权重结构；合成模型上的量化行为（exp2）；"反演模式 = 文献 UBP 的单环平面应用"。
- 若阶段 C 质量对比显示该近似不足，升级路径为 FHR log 核 FBP（需独立任务与架构变更），不在本任务内。

### 1.5 与 MATLAB 注释的核对结论

`bp = 2*p − 2*t*dp/dt`（das_recon_circular_gpu_v2.m 头注释）= PRE 2005 的 b 项 ✓（组合本身正确）。但：(a) 注释未给出权重与归一化（生产旧默认 q=1+accW 与 UBP 配对不同）；(b) 未说明严格性边界。本阶段以其为**出发点**而非**依据**，依据以 PRE 2005 原文 + 数值验证为准。

## 2. 时间轴与索引约定（exp3 已验证）

### 2.1 索引链（与 starting SHA 代码逐行对应）

- 原始行样本 m（1 基，1..sampDepth）。
- `preprocessBlock`（ring_recon.cpp:118–127）：delayCut=1 时输出行数 = Nt−sysDelay+1，输出样本 k（1 基）= 原始样本 **k+sysDelay−1**；delayCut=0 时 k=k。
- CUDA/CPU 查询（ring_das_kernel / dasReconAppend）：tf=d·fs/c(+分层) 为连续采样数；1 基样本 k 位于连续坐标 **τ=k−1**；线性插值 v(τ)=col(k)+frac·(col(k+1)−col(k))，k=floor(τ)+1，maskOob 越界置零。
- 因此：τ ⟷ 原始连续样本坐标 **m(τ)=τ+sysDelay**（delayCut=1）或 **τ+1**（delayCut=0）。

### 2.2 声学时间约定

- 原始样本 m 的声学时间定义 **t(m) = (m − sysDelay)/fs**：sysDelay 为经验校准的"触发→声学零点"截断起点，裁剪后每根线的 τ=0 即该波长/通道的声学零点。
- **不把 systemDelay 加回 t**：加回等价于把声学零点移到原始样本 1，与生产 DAS 已验证的对齐矛盾；且每通道/波长 sysDelay 不同（358/371，sysDelayPerChannel 协议），各线裁剪后各自自洽。
- delayCut 两态查询公式：
  - delayCut=1：**t(τ) = τ/fs**；
  - delayCut=0：**t(τ) = (τ + 1 − sysDelay)/fs**（可为负；该区间位于 DBR 置零/触发前区，由 §5.5 有效区间排除）。

### 2.3 脉冲测试结果（exp3）

- T1 索引链：raw 构造（声学零点在样本 sysDelay）→ 裁剪 → 峰位 τ=671.00 vs 期望 671.14（−0.14 样本，网格量化内）。
- T2 对齐：p 峰插值偏差 −0.140 样本；p′ 过零偏差 +0.010 样本；b 主过零偏差 **+0.003 样本**——p/p′/b 三者无 ±1 错位。
- T3 delayCut=0：raw 峰 m=1029 vs 期望 1029.14；t 公式自检误差 −0.56 ns。
- T4 一采样点敏感性：sysDelay 偏移 −1/+1 时 b 主峰偏移 +2.860/+0.860 样本（差恰 2.0 样本）→ 脉冲测试可明确排除/发现一采样点错位（任务 §7.1 要求项）。

## 3. 滤波顺序与端点约定（exp5 已验证）

### 3.1 冻结的处理顺序（每根 A-line 独立，无跨线状态）

```
raw(m) → [DBR 置零 1..maskLength+dbrmaskExtra] → [削顶 ±imValue] → [DelayCut]
       → 高通零相位（整条裁剪线）→ 低通零相位（整条裁剪线）
       → [反演关] 直接进 DAS 查询   /   [反演开] 导数 p′ → b → UBP 查询
```

- 与现状的差异：现有生产默认滤波全关；开启后滤波作用于**裁剪后的整条线**，而不是 MATLAB 历史的 301:/sysDelay+20: 切片。
- 理由：(a) 切片起点（301、sysDelay+20）落在查询区间内，滤波在数据中间"凭空开始"无稳态依据；(b) exp5 显示整线稳态方案的起点瞬态（984.7）不劣于切片方案（1076），burst 拖尾一致（1747 vs 1743 样本）；(c) 全部开关关闭时逐位保持现状（顺序不生效）。
- DBR 硬置零阶跃不被求导：默认参数下 maskLength+extra(313) < sysDelay(358/371)，裁剪线不含置零阶跃；非默认配置见 §5.5 有效区间。
- wl2 跨块尾线：滤波在逐线预处理时完成（ImagingSvc 的 `preprocessBlock` 调用点），shiftWL2 前插的尾线是**已处理**线，天然满足"只处理一次"（阶段 B 实现位置约束）。

### 3.2 滤波器规格（冻结）

- 设计：`butter(n, Wn, ftype)`，**Wn = 2·fc/fs**（fc 为单程 −3dB 截止），`zp2sos` 转 double SOS；高通 `filterLow/wLow/n1` → fc=0.4MHz、n=4 默认；低通 `filterHigh/wHigh/n2` → fc=40MHz、n=4 默认；首版阶数 1–8。
- 零相位：前向 → 时间翻转 → 前向（同系数）→ 翻转；奇对称延拓两端各 **nfact = 3n**；逐节稳态初始化（DF2T：s₁=y−b₀x₀，s₂=y(1+a₂)−x₀(b₀+b₁)，级联传递）；复合增益 **g²**（前后向各一次——参考实现曾漏乘一次导致恰好 1/g 偏差，已修复并记录）。
- 复合频响：fc 处单程 0.7071（−3.01dB）、双程 0.5000（−6.02dB）——解析计算精确成立（exp6 F1，9 种设计）。UI 文案须写明"双程 −6dB"。
- 顺序：高通先于低通（单独/组合均可）。
- 报错条件：线长 ≤ 3n（exp5 A5：12 报错、13 正常）；输入含 NaN/Inf 报错。
- 数值：内部 double；输出保持 float；导数 dp/dt 用中心差分（端点单侧，即 MATLAB `gradient(·, 1/fs, 1)` 语义），在滤波后、反投影前计算一次。

### 3.3 记忆长度与有效区间（阶段 B 使用）

- 零相位冲击响应展宽（1e-6 峰准则）：0.4MHz 高通 n=1..8 → **848/1125/1603/1914/2446/2783/3101/3639 样本**（exp6 F5）；40MHz 低通 ≪1 样本量级（可忽略）。
- 含义：线起点/终点约 1.5–9µs 内的输出依赖边界约定（稳态+奇延拓），与理想无限长响应的偏差在该范围内衰减。该区间对应像素-探测器距离 d ∈ [0, mem·c/fs]。
- **有效区间定义（反演/DAS 通用）**：查询样本索引 i（原始行坐标）需满足 `i ≥ max(sysDelay, dbrEnd+1) `（DBR 阶跃及其置零区排除；默认参数下 = sysDelay，即全区有效），并建议阶段 B 对反演模式增加可配置的起点裕量（默认 0，建议值 ≥ 高通记忆长度，待实机数据评估后定）。delayCut=0 时同理以原始行坐标表达。
- 起点瞬态实测（exp5，burst 2000 幅度合成）：两顺序起点 50 样本 |out|max = 984.7（N）/1076（M），burst 拖尾（>1% 峰）均 ~1745 样本——**burst 残余是瞬态主导项，边界约定是次级项**。

### 3.4 交叉验证与容差（exp6）

- refZeroPhase（共享参考实现，C++ 目标算法）vs 经典 **tf 形式 filtfilt**：DC/带内/带外正弦/多音/居中冲击/启动 burst/噪声 上，HP 全段相对差 ≤ 2.03e-8、LP ≤ 2.33e-15（'dc' 项退化比值无意义除外）。
- 阶数扫描（0.4MHz HP，多音）：n=1/2/3/4 → 1.3e-15/1.8e-13/1.3e-10/7.4e-9；**n≥5 tf-filtfilt 自身病态**（filtfilt 求初态矩阵 RCOND=2.3e-17，n=8 偏差 1.0）——tf 形式系数在 Wn=0.0032 高阶失稳。**结论：C++ 采用 double SOS；tf 形式仅作 n≤4 交叉验证基准；n=5–8 以参考实现自身 + 长信号一致性为准**（refZeroPhase 与"零初态+超长延拓"在冲击测试中部一致，冲击测试本身即为无约定依赖的校验）。
- 供阶段 B 的 C++ 数值测试：`evidence/filter_reference_vectors.mat`（输入 7 种 × HP/LP 输出 × p′ × b 向量 + SOS 系数 + 版本/约定元数据）。建议容差：内部样本相对 1e-6（double 一致性），端点 nfact 区间相对 1e-3（C++ 与参考实现实现顺序差异）。

## 4. 几何权重与归一化（exp2 已验证）

### 4.1 反演开启（配对方案）

- 权重：`Wᵢ = apodᵢ·Δθᵢ·R·cosαᵢ/dᵢ²`（立体角/单位 z 长度，§1.3）。
- 归一化：**accW**（`acc/max(accW,1e-12)`）。证据（exp2，均匀盘 f₀=1、ROI<4mm）：
  - DAS q=1：CV=0.0901；
  - UBP+accW（D）：**CV=0.0874**（最优，且与生产 snapshot 的 `acc/max(accW)` 路径完全兼容，无需改显示链路）；
  - UBP+原始和（P）：CV=0.1909——单环下 ΣW 随位置变化（环心 2π/R → 近环更大），绝对标度不守恒；
  - 高斯点峰值位置稳定性：D 模式 0.30→10.6 仍随位置变化（近场主导效应），P 模式 0.25→71.6 更差。
- 若审查要求物理标度（P 方案），需改 snapshot 分支（acc 不除 accW、常数 C 标定）——列为备选，不推荐 v1。

### 4.2 反演关闭

逐位回到旧默认 q=1、apod none 基准（任务回归基线 §11）；`distanceWeightExponent` 前端退役、后端旧指数计算按任务 §7.3 以局部注释保留。

### 4.3 错误配对（反证，任务约束的依据）

UBP 信号 b + 旧 DAS 权重（Δθ·cosα/d）：位置误差 2.0–2.83mm、FWHM 4.0mm（配对方案 0.6–1.2mm / 0.4–1.6mm）——"只换输入不换权重"产生实质性劣化，禁止。

### 4.4 环外像素与近场（新发现，阶段 B 决策项）

生产 FOV 直径 36mm（半径 18mm）**大于**环半径 R=6.57mm：环外像素的 cosα<0（近侧探测器）、立体角权重符号翻转且 1/d² 发散（exp2 点 4 位于 (−5,5)mm 即环外 0.5mm，原始和式幅度 71.6 = 近场伪影）。Ubp 公式的精确性仅在环内成立。阶段 B 选项：

- (a) 反演模式将环外区域照常计算但文档标注"未验证"（最小改动）；
- (b) 反演模式对 `dᵢ` 设置近场下限或在权重中掩膜环外贡献（改动小但引入新参数）；
- (c) accW 归一化天然抑制近场发散（exp2 显示 D 模式 nearMax 8.5 vs P 15.9），可作为部分缓解。
本阶段推荐 (a)+(c)，(b) 留待实机数据。

### 4.5 minDistance / apodization

- minDistance 保留数值保护（默认自动 = gridSize），只作用于权重分母（与现状一致）。
- Apodization 默认 none；基准验收固定 none；apod 作为权重的可选乘子保留（非 UBP 数学的一部分，文档明确）。块内 j/N 周期窗的重写不在本任务范围。

### 4.6 导数项主导与滤波的耦合（提示）

`k·r ≫ 1` 时 `r̃·p′ ≫ p`（PRE 2005 原文 §III；exp2 实测 b 中导数项比 p 项大 2–3 个量级）——反演模式对高频噪声放大，**低通零相位滤波与反演联用是预期用法**；阶段 C 质量对比按任务 §10 的四态矩阵（原 DAS / 仅高低通 / 仅反演 / 全开）执行。

## 5. 双声速（exp4 已验证）

- 沿用生产分层直线走时模型（ring_recon_cuda.cu:297–315）：`tf = d·fs/c_outer + Σᵢ Lᵢ·fs·(1/cᵢ−1/cᵢ₊₁)`。
- 独立验证：生产判别式弦长 vs 独立代数路径（垂距+半弦长裁剪）400 对随机几何 max|ΔL| = **3.17e-17 m**（机器精度）；同声速双层 vs 单声速全网格 max|Δτ| = **4.5e-13 样本**；分层前向+分层重建（模型自洽）峰值位置误差 **0.000mm**（吸收体在原点、跨边界直线）。
- 声明：反演模式在分层介质下与 DAS 同为直线近似——不实现折射路径/透射幅度，不宣称非均匀解析反演（任务 §6）。分层 τ 与脉冲放置的"模型自洽性"已验证；与真实双声速介质的偏差属物理模型误差，两模式共有。

## 8. 限制与未验证项

1. **无真实数据**：全部数值参考基于闭式合成模型（均匀盘/球、高斯吸收体、合成 burst）。真实 14.dat 链路行为、真实噪声下的表现未验证——任务 §10 的真实数据项标注 UNVERIFIED。
2. **质量收益未确立**：exp2 合成体模上，反演与 DAS 互有胜负（UBP-D 切向 FWHM 最优 0.96mm vs DAS 1.34mm，但远场伪影 std 高于 DAS）。"反演更优"的结论必须由阶段 C 同数据四态对比 + 实机给出，本阶段不做此宣称。
3. **无噪声/无采集链路非理想**：未建模采集噪声、量化、丢块；零相位滤波的噪声放大（尤其反演导数项）仅作定性提示（§4.6）。
4. **环外区域**（§4.4）与**非默认 DBR/sysDelay 配置**（§3.3）需阶段 B 落地决策。
5. **性能**：未测（阶段 C）。反演模式 CUDA 每线多一次插值 + 每线一次 CPU 导数，开销预估在逐块预算内，待实测。
6. 2D 近似的系统偏差（单环 vs 完整孔径）未做体模外的研究；FHR 升级路径见 §1.4。
